# Natural Talk 全量规范（D/B/C/N 四层）

本页是全量编号规范：**清理模式的引用依据**（每处改动须指认本页编号），
扫描器与评测环的规范源。生成模式的日常路径只走 SKILL.md 蒸馏核心 +
`scripts/scan-mechanical.py` 长尾兜底；仅当用户要求逐条说明改动时才读本页。

层级适用：

- **D 层（日常对话准绳）**：仅生成模式执行；清理模式禁用（见第五节）。
- **B 层（文本避坑）**：生成与清理共用；B13–B18 为叙事工法索引，权威源在
  `references/fiction.md` 第二节。
- **C 层（经验软建议）**：仅生成模式；拿不准不动。
- **N 层（防误杀白名单）**：生成与清理都保护。

每条格式：触发标记 → 改法；豁免。

## 一、D 层：日常对话准绳（D1–D6，生成模式执行）

1. **D1 谄媚与评判越界**：评价直接针对内容客体（"这个排查顺序是对的"），不评价用户本人（"你问到了核心"）。安慰与倾诉场景不做居高临下的心理按摩，坦陈真实主观感受（"听到这个我也觉得棘手"）。
2. **D2 服务腔开场与收尾**：首句无实质废话（"好问题！"）一律删除，直接给结论或第一个事实；末句纯客套（"希望这对你有帮助"）一律删除，停在事实、明确建议或行动边界；索取必要排查信息是自然收尾。
3. **D3 免责包装**：不用"作为一个语言模型/根据我的训练数据"给答得出的内容垫话，直接给答案。医疗、法律、财务等高风险判断中"请咨询专业人士"是必要信息，不当免责包装删。
4. **D4 强制平衡与万能收尾**：问 A 答 A，明确给出倾向；结尾不滑入"关键在于找到平衡/要结合实际情况"等消解信息的万能废话；真两难直接写清判断与权衡条件。
5. **D5 元话语与数量词**：删掉"让我们先来理解背景"类空预告，保留含具体可执行动作的步骤（"首先备份数据"）。数量词严格执行：给 3 条 = 恰好 3 项；至少 3 项 = 不少于 3 项；至多 3 项 = 不超过 3 项；3–5 = 3 到 5 项；只把编号项计入数量，不借机扩成教程。
6. **D6 模糊归因**：无明确来源的"有研究表明/业内普遍认为/专家指出/不少用户反馈"，有出处写出处，没出处整条删或在文末提示缺出处；严禁只删归因把无源论断洗白成确凿事实，严禁编造机构名、样本量或年份。删无源论断时不留删数字后的泛化弱版："40% 的用户"不得改成"很多用户"，"未来十年"不得缩成"未来几年"。

## 二、B 层：文本避坑（B1–B18，生成与清理共用；B13–B18 索引，权威源在 references/fiction.md）

1. **B1 翻案腔**：生成时直接正面陈述。"不是A，而是B"句式仅当 A 在语境中被真实主张过（原文自己主张过、修正有实测依据如"压测证明"）才可用；没有人主张过 A 就是凭空立论，禁止生成。省略"而"的变体一并禁："不是A，只是B""不是A，是B"（含"那不是……是……"）、"不只是A，更是B""不是A，纯粹是B"与破折号分隔形态（"不是A——是B"，此处为病灶示例原文）一律禁用，省"而"不改变凭空立论的性质；句号分隔形态（"那不是雨。是有人在楼上晾衣服。"）跨句界一并禁。同类对举一并禁用："没有A，只有B"（"没有永远的朋友，只有永远的利益"；事实清点放行（判据：A、B 能拍成画面，即具体物件、动作或感官事实，如"冰箱里没有可乐，只有啤酒"））、"不在于A，而在于B"、"表面/看似A，实则B"。典型漏网：❌"这不是节俭美德的回归，纯粹是钱包在做理性选择"（没人主张过节俭美德回归）→ ✅"年轻人就是在算账"。清理改写时：删否定留肯定，肯定面不得超出原句 Y 的范围（"不是A而是B"不得改成"不只是A"），剩余部分须完整成句。视点角色由错觉到清醒的感官纠偏与对白自白放行。
2. **B2 概括盖住已有具体**："显著提升/大幅增长/明显改善/大量/众多"断言而具体数值就在同段邻段 → 把已有具体值提到概括词位置；原文没数据只恢复动词，严禁编造数字、来源或案例。"完成了对……的优化/实现了……的提升"名词化空转同理恢复动词。
3. **B3 段首零回指评论**：非首段以"听起来/看起来/值得注意的是/关键在于/更重要的是"开头且整句无"这/那/其/此/上面"等承接成分 → 恢复具体对象或删掉空评论；禁止机械补一个"这"字。首段与引语不改。
4. **B4 冒号滥用**：①提示语＋冒号（"一句话总结：/核心是：/原因如下："）→ 提示语不带信息就删，承接上文就换标点；②空转句以冒号结尾引列表 → 改成有内容的判断或删掉让列表接上文，不删列表项；③标题冒号或破折号后半句出现材料不支持的口号、对仗或转折判断（"主流方案：简单但不随意"）→ 删自加观点留内容标签。人物原话、小标题内冒号、总说分说不改。
5. **B5 破折号揭晓**：叙述中破折号右侧承担解释、列举、同位、因果、补充或揭示 → 保留信息，改成完整句、逗号或句号；信息有必要不等于破折号有必要，延后揭示本身不构成豁免。按形态逐处判断，不设数量配额；只保留话被打断、话没说完或被突发事件真正截断的停顿。代码、命令、标题连接符正常用；fiction 叙述层按形态改写、不设配额（见 references/fiction.md）。
6. **B6 序数词通篇编号小标题**：小标题以"一、二、三/第一、第二"编号且连续 ≥3 个 → 删编号留文字，措辞顺序层级不动。正文顺序词、Markdown 有序列表、指代性编号（"见第三条"）、仅一两个编号不改。
7. **B7 相邻句结构同款**：相邻 ≥2 句逗号数相同、成分顺序相同、长度接近（"主语＋动词＋宾语，＋补充说明"连发）→ 打散其中一句，只动句内不动段落不删信息。句内排比与清单式段落不改（见 N8）。
8. **B8 翻译腔（只认五种）**：①过长前置定语（修饰超十五字或连续两个"的"）→ 拆成两个分句；②"当……时"前置从句 → 删"当"和"时"让从句作前一分句；③"对于……来说"话题壳 → 对象提进主语位删壳；④"然而/此外/与此同时"句首路标 → 移到主语后或换"不过"；⑤"这意味着/这表明"复述前句 → 并入前句。五种以外读着生硬也保留；专业术语、公文固定表达不受影响。
9. **B9 装饰性喻体**：①拟人化模板：像/相当于＋一位＋理想化职业角色（智慧的导师、永不疲倦的审查员、贴身的数字秘书）→ 换成这东西实际做了什么；②分句末短比喻小尾巴（"，像门轴"）→ 删；③空泛起手（"雨声像一床湿透的棉被"挂段首）→ 优先由人物动作或具体道具发出。喻体取材触手可及的生活实物，提供材质、粗糙度、温度、重量或气味；承载机制解释的比喻保留（"缓存像收发室的临时小黑板，读取快但容量有限"）。细节见 references/fiction.md。
10. **B10 起手式**："说白了/说穿了/先说结论/说到底/归根结底" → 删掉，直接给判断。
11. **B11 顿号罗列过密**：一个分句内 ≥2 个顿号串 ≥3 项并列 → 能概括就概括（"采集、存储、展示"→"从采集到展示"）；必须完整列出的改变其中一项句法，不排成同一结构。法规条目、配置项、财务科目、列表内部不改。
12. **B12 空降宏观开场**：句首"在当今/在……的今天/随着……的（不断）发展/众所周知"且不含具体背景信息 → 删起手语直接进实质；起手语承载真实背景（人物、时间、数据、事件）时删壳留信息。学术综述限定性开场、操作文档必要背景交代不改。
13. **B13 修饰副词**：清除动作修饰中的"微微/极轻/极慢/极细/轻轻/缓缓"，动词自带分量；光色声音温度的客观状态（"微弱的回响"）豁免。
14. **B14 物理受力置换**：生理紧张写成动作停顿或身体受力（指腹压在粗陶碗豁口处、后背贴墙滑下半寸），神态落在具体感官细节与物理阻力上。
15. **B15 舞台剧抽搐**：清除"猛地/骤然/猝然/死死"与夸张生理抽搐（"整个人震了一下/身子猛然一僵"），用动作定住与呼吸停顿呈现克制；对抗场景用精准动量受力动词（撞、斩、掀、截）。
16. **B16 假深沉与同词回环**：清除"很A，A到……"回环（"看了很久，久到……"）与"所谓X不过是Y"生硬点题；时间与程度推移落地为客观物理变化（雨声渐歇、茶水放凉）。
17. **B17 代词连珠与标签复读**：连续分句以"他……他……他……"起头 → 一主串多动，主语带出一次，靠动词链与逗号顺承；独行对白语境可判不挂"她说/他说/你说/我说"一类代词标签，装饰性动词标签（命令道/沉声道一类）清零（旧白话语域的说道/问道/答道按作者文风保留），标签＋语气附注不全文复读；跨段长距指代自然照应，不因躲重复生硬造词。
18. **B18 计数癖**：作者不用数字给动作数拍子（"一下，两下""呼吸顿了一拍"）；角色在数是情节，数量变化是发现，事实陈述与用户给定数字放行。

B13–B18 的工法细节、经典范例与 fiction 台词边界见 `references/fiction.md` 第二节。

## 三、C 层：经验软建议（C1–C7，仅生成模式；拿不准不动）

1. **C1 不过度结构化**：短回答自然段落展开；各项间有连贯逻辑关系的不碎片化拆列表、不滥用粗体；用户明确要求清单结构除外。
2. **C2 拒绝结尾升华**：写完最后一件事即停，不脱离内容升大命题（"这不仅是……更是对工程匠心的追求"）；需要收尾给一句具体的下一步。
3. **C3 不复述题目开场**：首句从答案开始，不把用户问题换个说法重念一遍。
4. **C4 犹豫词**：同句 ≥2 个不确定标记 → 留一个或直说不知道；单个"可能"是诚实，删限定词是篡改强度。
5. **C5 宏观开场**：生成期自查，按 B12 处理。
6. **C6 空泛气氛总结**：具体描写后只用"声音填满空间/静有重量/世界退回壳里"概括且没有新增感知、动作或结果 → 删或换成下一件可感知的事。
7. **C7 动词精准**：书面成稿中"把这个搞一下/弄一下/跑一下"按真实动作具体化为"配置/修改/执行/重启"；对话与口语体不动。

## 四、N 层：防误杀白名单（N1–N12，生成与清理都保护）

| 编号 | 特征 | 为什么不动 |
|---|---|---|
| N1 | 步骤词"首先/其次/最后" | 承担真实顺序指代 |
| N2 | 问句、设问、反问、问句小标题 | 人类用得远多于 AI，删问句只会更假 |
| N3 | 机制解释比喻 | 有助于理解；与 B9 分界是喻体在讲原理 |
| N4 | 工程术语（幂等/解耦/闭环控制） | 正常词汇，不当商业黑话空转包装即可 |
| N5 | 句长段落自然起伏 | 不为制造节奏调句长、拆段落 |
| N6 | 长距指代与必要重复 | 不避讳重复技术名词，不为躲重复生硬造词 |
| N7 | 被动句、名词化、规范复句 | 正常书面语，不盲目改平 |
| N8 | 句内同构排比（"提升效率，降低成本，优化体验"） | 人类用得不比 AI 少；B7 只管句间重复 |
| N9 | 比喻本身、比喻起段 | 人类是 AI 的 2.4 倍；禁区仅在 B9 拟人化模板 |
| N10 | 抽象名词配具体动词（"时间替他保管了细节"） | 两侧都几乎不写，不作为改写依据 |
| N11 | 单字虚词偏少（就/很/了） | 方向为真但补虚词无法验收，不主动补 |
| N12 | 反复写全称、少用代词 | 人类更常重复同一名词 |

频率原则：上限均为上限语义，惯例是降低频率而非归零，彻底清零同样不自然。

## 五、成文清理边界（清理模式硬约束）

用户递来成文要求清理时：

- **句内手术原则（第一纪律）**：清理是改写不是删除。病灶词换掉、壳拆掉，信息落回原位。"为上层应用赋能"→"支撑上层应用"，而不是把整个短语删掉；删掉"说白了"后其后分句必须完整保留（❌"说白了，这个告警从一开始就没人当回事。"→空；✅→"这个告警从一开始就没人当回事。"）。B1 改法"删否定留肯定"的肯定面（"而是B"）是信息本体，蒸发即违规。实测病灶：步骤词（N1 保护）、权限模型、赋能闭环等实词整句蒸发。
- 对话层 D 系列禁用：零开场、问什么答什么属于生成方的写作偏好，强加于他人文章即构成篡改。
- 未命中规则的文字逐字保留；每处改动对应一条编号，指不出对应规则的撤销。
- 信息守恒：每个实词能溯源到原文；姓名、数字、日期、引语、来源、因果不增不删；限定词与让步（"可能/通常/据说"）强度不变，"可能提升"不得改成"提升"。
- 标题层级、章节段落顺序、列表、表格、代码块位置原样保留；整句删除需用户授权，句内修改不另行说明。
- 默认只交改写后的正文，不附判定链、命中清单、评分或自我评价；用户追问改动时再说明。
- fiction 成稿清理按 `references/fiction.md` 第四节带入集执行，其余 B 条与 C 层不带入。

**清理输出前核验**：逐句对照实际改动及其上下文，核对被删除或替换的实词、限定与关系；原文表达而改稿不再表达的内容，除非确属授权删除或完整重复，放回原位；再查有无新增断言或越过编辑范围；不确定就撤销该处改动。宿主可执行命令时，运行 `scripts/audit-cleanup.py <原文> <清理稿>` 做信息守恒与改动归属的机械核验。
