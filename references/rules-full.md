# Natural Talk 清理规则

本页是清理模式的规则依据：R1–R10 的判据与删除授权边界；每处改动须严格指认本页规则编号。

代码评审意见、PR 描述、commit message 与技术长文先按 `SKILL.md` 成稿，成稿后再按本页 R1–R10 查一遍。

叙事形态 B1–B9 的定义与小说形态判据详见 `references/fiction.md`；fiction 清理同时读取该页。「清理边界」与「fiction 清理规则」仅在清理模式下生效。
D 层（服务型迎合开场、万能收尾、空预告、模糊归因、身份垫话）的定义在 `SKILL.md` 的 D 层，仅作用于生成模式；诊断交付引用编号时，对话层采用 D1–D5，本页不展开。

判断类规则中缺乏纯机械判据的规则：R2、R6 与 R3(2) 须逐条依据语境人工判定；R7 的明喻形态可通过句式结构检出，但喻体是否承载有效感官增量仍由人工审慎裁定。

## 一、R 层：文本避坑（R1–R10）

R1 翻案腔：未在前文或用户提问中确立 A 之前提时，禁止使用“不是 A，而是 B”的反转对举结构。仅当 A 在语境中被真实主张时方可保留：前文已明确主张、修订具有明确验证材料（如“压测数据证明”）、或用户提问中已显式陈述该前提（在纠错与否证语境中，该句式本身即为有效结论）。
    - 判定依据：前文、用户前提或验证材料确立过 A，整句予以保留。未被主张过的空泛否定成分必须剥离，完整保留肯定侧。若否定侧排除了某种具体技术或客观事实可能性，须调整为肯定侧前置、否定侧整句后置。❌“真正的瓶颈并不是技术，而是耐心。” → ✅“真正的瓶颈是耐心，并不是技术。”
    - “不仅是 A，更是 B”按本条候选范畴处理：逐一判定两端是否空泛；A 端空泛剔除 A 保留 B，B 端空泛剔除 B 保留 A；两端皆具实质内涵时予以规范保留或按陈述语气合并为单句，严禁丢失实质信息。
    - （纠错放行 ✅“不是缓存的问题，是连接池打满了。”：用户既有前提“缓存未生效”被排查证伪，直接纠错结论合法放行。）
    - 省略转折词“而”的各类变体一并归入本条规制：“不是 A，只是 B”“不是 A，是 B”（含“那不是……是……”）、“不只是 A，更是 B”“不是 A，纯粹是 B”、破折号分隔形态（“不是 A——是 B”）以及句号断开形态（“那不是终点。是新的起点。”），无论是否省略连词或跨越句界，均未改变凭空翻案或空泛拔高的属性。
    - 具备可观察性的否定陈述属于事实，予以保留。❌“没有惊心动魄的转折，只有日复一日的磨损。” → ✅“只有日复一日的磨损。”；“有人看见了风险，只是没人愿意……”严禁颠倒为主谓改动。否定与限定属于叙述立场的一部分。
    - “没有 A，只有 B”（如“没有永远的朋友，只有永远的利益”）同属对称对举框架，一并按本条判定；A、B 均为可指认的具体物件时（如“冰箱里没有可乐，只有啤酒”）按客观事实陈述予以放行。
    - “不在 A，在 B”结构，以及接在否定侧之后的自我对照（如“他不是不在乎，其实是累了”），均按本条候选规则处置。
    - “没有 A，只是/只有 B”结构中，若 A、B 均为动作主体的并列行动（如说话、回头、快步前行等），并非事实陈述：剔除“只是/只有”虚词，将两个动作连缀表述（如“他没有说话，只是拉过她的手”重构为“他没有说话，拉过她的手”）。
    - 典型病灶：❌“这不是一次普通的版本更新，而是一次范式转移。”（语境中从未有人主张“普通更新”）→ ✅“这是一次范式转移。”
    - 典型病灶：❌“这不是节俭美德的回归，纯粹是钱包在做理性选择”（语境中无人主张美德回归）→ ✅“这是钱包在做理性选择”。
    - 肯定侧表述不得超出原句 B 的内涵范畴：“不是 A 而是 B”严禁篡改为“不只是 A”（该改动将否定反转篡改为程度递进），修剪后的剩余部分须语法完整且能独立成句。
    - 清理豁免：否定侧指涉文学体裁或创作手法判断（词表参见 N14）时，否定内容属于作者的审美判断，予以保留。
R2 概括替代已有具体（判断类规则）：同段或邻近段落已列明确切参数指标，行文中却抽象使用“显著提升/大幅增长/明显改善/大量/众多”等定性断言替代事实。生成模式下应使用平实动词陈述，严禁虚构数值、伪造来源或捏造案例。清理模式下一律保留该类既有概括词，亦不将邻近数值强制嵌入原句；“完成了对……的优化/实现了……的提升”等规范名词化表述同样予以原样保留。
R3 冒号滥用：(1) 提示语组合冒号（如“一句话总结：/核心是：/原因如下：/本质上：/关键在于：/直接给答案：”），剔除前置提示词，直接展开实体陈述。
    - 句首出现的提示词可直接剥离；句中出现的提示词须先行复核，确认剔除后不损失上下文逻辑信息再行删除。
    - (2) 标题冒号或破折号后半句出现缺乏客观材料佐证的宣传口号、工整对仗或转折断言（判断类规则，如“主流方案：简单但不随意”）。后半句是否获得事实支撑须通读全文严格判定。
    - 不改情形：小标题内部的结构性冒号且右侧属于客观属性标签时（如“部署：三步走”）；冒号前分句无实质内容仅作为列表导引时（如“实践中常见的几种典型场景：”后接详细列表）。
R4 叙述破折号：叙述文本中破折号右侧若承担解释说明、例证罗列、同位指代、因果阐释、补充说明或答案揭晓之语法功能，一律禁用破折号；信息必要并不等同于破折号必要，须逐处转换为规范完整句或常规标点，严禁丢失信息。
    - 依据语法功能形态逐处判定，不设置机械数量配额。揭晓定义为右侧补齐前文未予明言的原因或结论（如“他忽然明白了”后接“钥匙一直在锁眼里”），依本条重构为完整句子。
    - 例外情形：破折号用于体现语流断裂而非承接解释时不属于病灶。台词遭遇打断、思绪中断、话语未完、时间跨度或场景硬切等，此类右侧处于悬空或另起段落形态，不承担前述六种语法关系，一律原样保留。
R5 序数词通篇编号小标题：同层级小标题采用“一、二、三/第一、第二”等形式连续编号 ≥3 个，且下辖各节缺乏实质性独立承载内容时构成病灶。生成模式下，各章节确有独立充实内容时允许编号，严禁单纯为结构排版虚设空泛小标题。清理模式下已有编号保持原样。
    - 文学平行结构与清单段落同构率高，不按本条判。
R6 翻译腔（判断类规则，只认五种，生成与清理都改）：严格规范以下五类翻译腔结构：
    - (1) 超长前置定语（修饰成分超过 15 字或“的”字连续出现三个以上）；
    - (2) “当……时”前置从句；
    - (3) “对于……来说”前置话题壳；
    - (4) “然而/此外/与此同时”在同段或相邻段反复充当句首引导词，形成刻板行文节奏；
    - (5) 空洞对冲修饰：“从某种程度上说/在某种意义上/不得不说”等不改变信息确定度的多余修饰。
    - “这意味着/这表明”引发的简单复述：生成阶段严禁使用；清理阶段依规原样保留。
    - 本条剥离的仅为冗余语法外壳，绝不削减实质信息。
R7 装饰性喻体：(1) 拟人化模板隐喻：像/相当于＋理想化职业角色，或像/相当于＋系统、机械、自然类的固定比喻（如智慧的导师、永不疲倦的审查员、交响乐团、精密钟表、引擎、灯塔等）。独立专业术语（如“数据引擎”“灯塔项目”“规则引擎”）属于实体命名而非比喻，依 N4 规范原样保留，不按比喻处置；
    - (2) 句末逗号悬挂短比喻小尾巴（如“，像门轴”）；
    - (3) 陈腐滥俗比喻：不产生任何具体感官增量的比喻（如“像溺水者抓住浮木”“像一潭死水”“像受惊的小兽”“像安抚一只炸毛的兽”等）。
    - 常规单处明喻不强行改动；(2) 不做单处处置，仅当同一段落出现两处或连续段落均在收尾位置高频使用时，对相关分句执行结构重塑；(1)(3) 出现单处即行删除或重构喻体。
    - 喻体是否具备有效感官增量，取决于能否指认具体的物理质感（如材质、粗糙度、温度、重量、气味或确切物理形态）；无法呈现具象质感者一律按 (3) 处理。详细规则见 `references/fiction.md` B3。
R8 起手式（句首）：句首出现“说白了/说穿了/简单来说/简单说/先说结论/说到底/归根结底/综上所述/由此可见”等刻板过渡词。
R9 顿号罗列过密：单一分句内顿号出现 ≥3 个（即并列成分 ≥4 项）。具体名词枚举（人名、地名、店名、物件）、法规条目、配置项与操作步骤照抄；只有空泛同义堆叠才改写或概括。
R10 空降宏观开场：句首出现“在当今/在……时代（背景、环境）下/在……的今天/随着……不断发展（演变、进步、前进）/众所周知”且缺乏具象背景信息。
    - 若引导语紧密承载真实背景要素（人物、时间点、统计数据、客观事件），须剔除空话外壳，完整保留背景实体。

## 二、N 层：防误杀白名单（两种模式都适用）

| 编号 | 特征 | 为什么不动 |
|---|---|---|
| N1 | 步骤词"首先/其次/最后" | 承担真实顺序指代 |
| N2 | 问句、设问、反问、问句小标题 | 常见写法，删问句只会更假 |
| N3 | 机制解释比喻 | 有助于理解；与 R7 的分界：喻体在讲原理的是解释 |
| N4 | 工程术语与业务实词（幂等/解耦/闭环控制/赋能/中台/接口） | 术语按原词写，不因业务语境同义替换 |
| N5 | 句长段落自然起伏 | 不为制造节奏调句长、拆段落 |
| N6 | 长距指代与必要重复 | 不避讳重复技术名词，不为躲重复生硬造词 |
| N7 | 被动句、名词化、规范复句 | 正常书面语，不盲目改平 |
| N8 | 句内同构排比（"提升效率，降低成本，优化体验"） | 常见写法，不按句间重复判 |
| N9 | 比喻本身、比喻起段 | 常见写法；禁区以 R7 列名形态为限（拟人化模板与用滥的比喻出现一处就改，句末短比喻看同段与连段） |
| N10 | 反复写全称、少用代词 | 正常写法 |
| N11 | 类型文惯例生理反应（拼杀时咬紧牙关、坠崖前抓住岩石、血顺着额角流下来一类） | 类型文的常态笔法；风格文档或用户范文支持时按作者保留。本条不覆盖 B5–B7 词表点名的写法：词表点名的按词表判，N11 只管没被点名的反应 |
| N12 | 歌谣、誓言、叫名字、口头禅的有意重复出现 | 重复是结构需要，不按 B7 的同词回环判 |
| N13 | 行内引号内的他人原话、术语强调与用户提供的范文 | 用词不改 |
| N14 | 文体与写法判断词（写实、煽情、说教、铺张、留白、炫技） | R1 被否定的那一侧是这类词时，被否定的内容保留 |

## 三、清理边界

频率控制原则：比喻密度、剧变副词等上限按“不得超过”严格执行，不人为预设机械配额下限。

用户提供既有文本要求执行清理时：
- 改写完成后须逐句与原文复核比对：原句承载的实质语义必须完整保留于改稿中，或在核对审查时能确切说明合规删除依据。用户显式要求压缩篇幅时，严格依据指定比例执行。
- 确定性特征命中即可依规修正；依赖上下文语境判定的形态特征，须先行复核确认属于纯粹病灶后方可改动，判定存疑时遵循原样保留原则；过程中不输出中间候选清单。fiction 清理不设此层：词表命中（B4/B6/B8 等）依本节「删除授权边界」严格复核后处理。
- 第一准则：严禁损失信息。剔除病灶词汇，拆解空泛套话结构，核心信息须完整回填原处。剥离“说白了”之后，后续陈述分句必须完整保留（❌“说白了，这个告警从一开始就没人当回事。”删除后整句缺失即属违规；✅“这个告警从一开始就没人当回事。”）。R1 改写中保留下来的肯定侧（“而是 B”），以及承载事实信息时后置的否定侧（“并非 A”），均属于有效实质内容，删除即判定违规。
    - R1 审查回读：否定侧排除了某种具体客观可能性时，改写稿必须能够准确还原该排除语义。空泛否定剔除后仅保留肯定侧，不予回填。
    - 典型违规病灶：步骤指示词（N1 保护）、权限模型、赋能闭环等业务实词整句被非预期删除。
- 对话交互层规则禁用：客服式开场、问 A 答 A 等属于特定场景的交互策略，将其强加于通用论述文本构成对原意的擅自篡改。
- 未命中规则的客观文本实行逐字保护。每处改动须严格对应具体规则编号；若某处修改无法明确指认规则出处，必须撤销该处改动。整篇文本若无任何修改可归因于规则编号，须将全文原样返还，严禁为了体现修改痕迹而施加无意义篡改。
- 语义等价替换不属于合规清理：将“赋能”机械替换为“支撑”、将“完成了数据中台的搭建”压缩为“搭建了数据中台”，在信息维度完全等价且缺乏明确规则依据，此类文本必须原样保留。
- 业务词汇不单独进行孤立删减：包含明确技术对象、具体动作或业务结果的复合短语（如“为上层应用赋能”），严禁直接剥离词汇。本条不授予整句删除许可。
- 严禁擅自增补信息，亦不得遗漏要点：每个实词均须在原文中找到确切对应；实体名称、统计数据、时间日期、直接引语、客观出处及因果链条严禁增删；语气限定词与让步表述（如“可能/通常/据说”）的置信强度保持一致，“可能提升”严禁擅自修改为断言性的“提升”。
- 标题层级体系、章节段落组织序列、列表项、数据表格及代码块位置一律原样保留。仅当 B5/B6/B7 明确列明的纯套话（如“一股莫名的情绪涌上心头”“他猛地一僵”“许多年以后他才会明白”）经确认除套话外不包含情节线索、真实物理力度或运动速度，且剔除后分句语法保持完整时，属于规则明确授权删除范围；若承载了上述有效事实信息则必须予以保留。B8 问答乒乓中删除对白轮次的授权边界详见下节「fiction 清理规则」。除上述明确授权外，整句删除原则上须获得用户显式确认，句内微创修改无需另行声明。
- B7 同词回环、生硬点题及预告式钩子的触发语多属于主谓骨架（如“他不知道的是”“所谓陪伴不过是”），仅限剔除触发短语本身，严禁随意删除整句；若整句仅由该触发短语构成，依前述纯套话条款处置；出现多处完全同构的整句重复时允许删除整句。
- 删除幅度判定标准取决于该分句在套话之外所承载的成分：若剔除套话后仅残留单一指称主语（如人称代词或“年轻人”等简短称谓），则连同主语一并剔除；若仍包含具体动作、物理物件或因果逻辑，则仅剥离套话本体。
- 默认仅交付改写修正后的正文结果，不附带判定推导链、规则命中清单、量化评分或自我评价；仅当用户追问修改细节时予以对齐说明。诊断模式（用户显式声明仅需定位问题、无需修改正文）不适用本条：该模式严格交付“命中位置＋规则编号＋判定理由”。
- 标点符号形态严格遵循原文：执行成稿清理时严禁改动任何既有引号形态，ASCII 英文半角直引号不擅自替换为中文全角引号，全角双引号亦不擅自转换为直角引号。
