# Natural Talk 清理规则

本页为清理模式的规则依据，包含 R1–R8 的判定标准与修改边界；每处修改均须对应本页的规则编号。

代码评审、PR 描述、commit message 与技术长文先按 `SKILL.md` 成稿，成稿后再按本页 R1–R8 复查。

小说规则 B1–B9 见 `references/fiction.md`；小说成稿清理同时适用该页。「清理边界」与「fiction 清理规则」仅在清理模式下生效。
D 层（D1–D6：迎合开场、无结论折中收尾、空泛预告、模糊归因、身份免责声明、否定用户未提及的问题）定义于 `SKILL.md`，仅用于生成模式；诊断模式引用对话层编号时使用 D1–D6，本页不重复展开。

需结合上下文判断的规则：R2 与 R3(2) 依语境判定；R6 的比喻句式易于识别，但喻体是否提供真实感官细节仍需结合语境判断。

## 一、R 层：文本规则（R1–R8）

R1 翻案句式：前文或用户提问中无人主张过 A 时，禁写“不是 A，而是 B”的反转对举。
    - 保留情形：(1) 前文已明确提及 A、修改具备实测依据（如“压测数据证明”），或用户提问已包含前提 A（如纠错时证伪“缓存未生效”：✅“不是缓存的问题，是连接池占满了”）；(2) A、B 均为现实中可指认的具体物件（如“冰箱里没有可乐，只有啤酒”）；(3) 客观存在的否定事实（如“有人看见了风险，只是没人愿意……”，不得倒装改为“风险有人看见了……”）；(4) 被否定一侧为文学体裁或写法判断词（见 N13）。
    - 修改方式：无人提及的空泛否定直接删去，仅保留肯定一侧（❌“没有惊心动魄的转折，只有日复一日的磨损。” → ✅“只有日复一日的磨损。”）。若否定一侧排除了某项具体技术或客观事实可能，改为**肯定在前、否定整句在后**（❌“真正的瓶颈并不是技术，而是耐心。” → ✅“真正的瓶颈是耐心，并不是技术。”）。
    - 同构变体：“不是 A，只是/是 B”（含“那不是……是……”）、“没有 A，只有 B”（如“没有永远的朋友，只有永远的利益”）、“不在 A，在 B”、紧随否定后的补充转折（如“他不是不在乎，其实是累了”），以及用破折号（“不是 A——是 B”）或句号（“那不是终点。是新的起点。”）断开的变体，均按本条处理。
    - 连贯动作：“没有 A，只是/只有 B”中，若 A、B 均为人物的连贯动作（如说话、回头、快步走），不属于对举修辞：删去“只是/只有”，将两个动作直接连贯表述（“他没有说话，只是拉过她的手” → “他没有说话，拉过她的手”）。
    - 语义与语法边界：肯定一侧不得超出原句 B 的含义，删改后保留的句子必须语法完整、可独立成句。
    - ❌“这不是一次普通的版本更新，而是一次范式转移。”（无人主张它是普通更新）→ ✅“这是一次范式转移。”
R2 概括词替代已有具体信息（依语境判定）：同段或邻近段落已给出具体参数指标，行文却用“显著提升/大幅增长/明显改善/大量/众多”等空泛词汇替代具体事实。生成模式下使用平实动词直接陈述，严禁编造数字、来源或案例。清理模式下原有的概括词保持不变，不将邻近数字强行并入原句；“完成了对……的优化/实现了……的提升”等正常名词化表述亦保持原样。
R3 冒号滥用：(1) 提示语加冒号（如“一句话总结：/核心是：/原因如下：/本质上：/关键在于：/直接给答案：”），句首提示语直接删去，句中提示语确认删去后不影响逻辑衔接再删，直接陈述正文。
    - (2) 标题冒号或破折号后半句为无事实支撑的口号、工整对仗或转折断言（依全文语境判定，如“主流方案：简单但不随意”），删去无事实支撑的口号部分。
    - 不修改的情形：小标题中的结构冒号且右侧为客观属性标签（如“部署：三步走”）；冒号前半句仅用于引出下方列表（如“实践中常见的几种典型场景：”后紧跟列表）。
R4 叙述破折号：叙述文中破折号右侧若为解释说明、举例、同位指代、说明原因、补充说明或揭晓结论（补足前文未明说的原因或结果，如“他忽然明白了——钥匙一直在锁眼里”），一律停用破折号；保留具体内容，将破折号改为逗号或正常断句，不得删减信息。按语法功能逐处核查，不设每千字数量配额。
    - 例外：破折号用于表示语流中断时不改。台词被打断、思绪中断、话未说完、时间跨度或场景切换等，破折号后无解释内容或另起一段，不承担上述六种解释功能，原样保留。
R5 序数词通篇编号小标题：同级小标题使用“一、二、三/第一、第二”连续编号 ≥3 个，但各节缺乏独立实质内容时应修改。生成模式下各节确有独立实质内容时可使用编号，不流于形式拼凑空泛标题。清理模式下原有编号保持不变；文学平行结构与清单段落形态相近的，不按本条判定。
R6 装饰性喻体：(1) 句尾逗号附着短比喻（如“，像烙铁”“，像羽毛”“，像宣判”“，像石子沉进水里”）：单处出现时保留，仅在同段出现两处或连续多段句尾均采用该结构时改入句内。
    - (2) 陈旧套话比喻与人物兽化比喻：无法提供具体感官细节的套话比喻（如“像溺水者抓住浮木”“像一潭死水”），以及将人物的神态、情绪、动作比作动物或野兽（如“像受惊的小兽”“像安抚一只炸毛的兽/猫”“像巡视领地的头狼/雄狮”“像蓄势待发的猎豹”“像温顺的大型犬”“像受伤的困兽”等），出现一处即删去或替换为具体比喻。
    - 感官细节判定：以能否体现具体物理特征（材质、粗糙度、温度、重量、气味或具体形状）为准；无法体现具体物理特征的按 (2) 处理。细则见 `references/fiction.md` B3。
R7 句首起手式：句首出现“说白了/说穿了/简单来说/简单说/先说结论/说到底/归根结底/综上所述/由此可见”等模式化过渡词。
R8 宏观空泛开场：句首使用“在当今/在……时代（背景、环境）下/在……的今天/随着……不断发展（演变、进步、前进）/众所周知”且未包含具体背景信息。若后接真实背景（人物、时间点、统计数据、具体事件），删去空泛前缀，完整保留背景事实。

## 二、N 层：豁免白名单（生成与清理均适用）

| 编号 | 特征 | 保留原因 |
|---|---|---|
| N1 | 步骤词"首先/其次/最后" | 确用于指代先后顺序 |
| N2 | 问句、设问、反问、问句小标题 | 正常修辞与结构，强行删改会损害行文自然度 |
| N3 | 机制解释比喻 | 用于辅助理解底层原理，属解释说明而非装饰性比喻 |
| N4 | 工程术语与业务实词（幂等/解耦/闭环控制/赋能/中台/接口） | 专业术语保持原词，不作同义替换 |
| N5 | 长距离指代与必要重复 | 正常重复技术名词，不为规避重复而生造词语 |
| N6 | 被动句、名词化、规范复句 | 正常书面语，不盲目改写 |
| N7 | 句内同构排比（"提升效率，降低成本，优化体验"） | 常见并列句法，不按跨句重复判定 |
| N8 | 比喻修辞本身、比喻开篇 | 正常修辞；仅限制 R6 列出的形态（陈旧套话比喻与人物兽化比喻出现即改，句尾短比喻视同段与连段密度而定） |
| N9 | 连续使用全称、少用代词 | 正常书面与工程文档写法 |
| N10 | 类型小说常见生理反应（如搏斗时咬紧牙关、坠崖前抓住岩石、血顺额角流下） | 类型文学常见笔法；风格文档或用户范文支持时按原文保留。本条不豁免 B5–B7 词表明确禁用的写法：词表列出的按词表修改，N10 仅适用于未列入禁用词表的反应描写 |
| N11 | 歌谣、誓言、呼喊姓名、口头禅的有意重复 | 重复属叙事或结构需要，不按 B7 的同词回环判定 |
| N12 | 行内引号内的他人原话、术语强调与用户提供的范文 | 用词保持不变 |
| N13 | 文体与写法判断词（写实、煽情、说教、铺张、留白、炫技） | R1 被否定一侧为此类词汇时，保留该否定 |

## 三、清理边界

频率上限原则：比喻密度、剧变副词等上限按“不得超过”严格控制，不设最低配额。

用户提供既有文本要求清理时：
- **核心原则：严禁丢失实质信息**。修改后逐句对照原文：原句的实质含义必须完整保留，或每处删改均能对应明确的规则编号。删去“说白了”等起手式后，后续正文必须完整保留（❌“说白了，这个告警从一开始就没人当回事。”整句删去属违规；✅“这个告警从一开始就没人当回事。”）。R1 改写后保留的肯定一侧（“而是 B”）以及排除具体事实而后置的否定一侧（“并非 A”）均属实质内容，不得删去。用户明确要求压缩字数时，按指定比例压缩。
- **不确定时不修改**：命中禁用词表与固定句式时直接修改；需结合上下文判断的句式，确认确属空泛套话后再修改，不确定时保持原样；过程不输出候选清单。小说清理中 B4/B6/B8 等词表命中同样须先对照本节删除边界核对后再修改。
- **不跨层套用对话规则**：D 层的迎合开场、切题作答、否定用户未提及的问题等属对话生成规范，清理既有论述文章时不得用于删改作者原文。
- **无规则编号不改、禁止同义替换**：未命中规则的句子逐字保留。每处修改必须能对应具体规则编号，无法对应编号的改动必须撤回；全文未命中任何规则时原样返回，严禁为体现修改痕迹而随意润色。将“赋能”替换为“支撑”、将“完成了数据中台的搭建”改写为“搭建了数据中台”，信息未变且无规则依据，一律不改；包含具体技术对象或业务结果的短语（如“为上层应用赋能”）不拆词单删，更不得整句删去。
- **不增补原文外信息、不改变确定度**：修改后每个实词均须在原文中有对应依据；人名、数据、时间、引语、出处与因果链条不增不删；语气限定词（“可能/通常/据说”）保持原有分寸，“可能提升”不得擅自改为“提升”。
- **结构与整句删除边界**：标题层级、章节段落顺序、列表、表格、代码块位置原样保留。仅 B5/B6/B7 列出的纯套话（如“一股莫名的情绪涌上心头”“他猛地一僵”“许多年以后他才会明白”）在确认不含情节线索、真实力度或速度，且删去后语法完整时，允许直接删去；包含实质事实的必须保留。B7 的“他不知道的是/所谓陪伴不过是”等句式仅删去触发短语本身，不删去后续具体事实（除非整句仅为该句空话，或多处整句完全重复）。删去套话时若分句仅剩代词或“年轻人”等无实质谓语的主语，连同主语一并删去；仍包含具体动作、物件或因果时仅删去套话部分。除上述情形外，整句删除须先征得用户同意，句内局部修改无需询问。
- **交付与标点格式**：默认仅交付修改后的正文，不附带推导过程、命中清单、评分或自评（用户追问时再逐条说明；**诊断模式**除外，诊断仅输出“命中位置＋规则编号＋简短理由”）。标点样式遵循原文：原文使用半角直引号则保留直引号，使用全角双引号或直角引号亦保持原样，不替换引号样式。
- **模糊归因按模式区分**：“有研究表明/业内（普遍）认为/专家指出/不少用户反馈”在清理模式下原样保留。生成模式下不把没有来源的结论写成事实；不得将无来源数字写为确定事实，不得将"40%"弱化为"很多"，不得将"未来十年"改写为"未来几年"。

### fiction 清理规则

- 风格文档优先：遵循 `references/fiction.md` 零、基本原则，句法、标点、用词与节奏优先服从用户提供的风格文档。
- 跨页带入规则：仅带入 R1 翻案句式、R4 叙述破折号、R6 装饰性喻体、R7 句首起手式。R5 序数词小标题在清理模式下不改，C 层行文建议不带入。
- 小说规则 B4–B9 的删除与密度标准同步生效；角色台词本身不改，仅修改叙述层；B8 全部子项按规范核查（对白行计入连续行数）；句首代词连用、句内主语重复与修饰性对白标签，核对删除边界后再修改。
- **禁止在清理模式下增补虚构细节**：B5/B6/B7 在生成模式下要求“改写为具体物理受力”，但清理模式下**仅允许删去纯套话，严禁自行替作者编造新的肢体动作、表情、生理反应或环境描写**。有风格文档或范文支持时按范文保留；N10 不豁免词表明确禁用的词汇，词表列出的词汇一律按词表处理。
