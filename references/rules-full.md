# Natural Talk 清理规则

本页是清理模式的规则依据：R1–R10 的判据与删除边界；每处改动须指认本页编号。

代码评审、PR 描述、commit message 与技术长文先按 `SKILL.md` 成稿，成稿后用本页 R1–R10 查一遍。

叙事形态 B1–B9 的定义与小说形判据见 `references/fiction.md`；fiction 清理同时读该页。「清理边界」与「fiction 清理规则」只在清理时生效。
D 层（服务腔开场、万能收尾、空预告、模糊归因、身份垫话）的定义在 `SKILL.md` 的 D 层，只作用于生成模式；诊断交付引用编号时，对话层用 D1–D5，本页不展开。

判断类规则里没有机器判据的：R2、R6 与 R3(2) 须逐条人工判定；R7 的明喻形态能按形态数出来，喻体有没有新增信息仍由人判。

## 一、R 层：文本避坑（R1–R10）

R1 翻案腔：没人主张过 A，却写"不是A，而是B"的句式。A 在语境中被真实主张过才可保留：前文自己主张过、修正有验证依据（如"压测证明"）、或用户提问中已陈述的前提（纠错/否证场景，这个句式本身就是答案）。
    - 判定：前文、用户前提或验证材料主张过 A，整句保留。没人主张过的空泛否定删掉，留下肯定侧。否定侧排除了一种具体可能时，先写肯定侧，否定侧整句留在后面。❌"真正的瓶颈并不是技术，而是耐心。" → ✅"真正的瓶颈是耐心，并不是技术。"
   - "不仅是A，更是B"按本条的候选处理：两端都判是否空泛；A 空泛删 A 留 B，B 空泛删 B 留 A，两端都实义则保留或按语气并成一句，不丢实义侧。
   - （纠错放行 ✅"不是缓存的问题，是连接池打满了。"：用户前提"缓存没生效"被证伪，直接纠错。）
   - 省略"而"的变体一并按本条判："不是A，只是B""不是A，是B"（含"那不是……是……"）、"不只是A，更是B""不是A，纯粹是B"、破折号分隔形态（"不是A——是B"）与句号分隔形态（"那不是终点。是新的起点。"）一律按本条判，省"而"或跨句界都不改变翻案或空泛拔高的性质；
    - 可观察的否定是事实，保留。❌"没有惊心动魄的转折，只有日复一日的磨损。" → ✅"只有日复一日的磨损。""有人看见了风险，只是没人愿意……"不能改成"风险有人看见了……"。否定与限定是态度的一部分。
   - "没有A，只有B"（"没有永远的朋友，只有永远的利益"）同为对举壳，一并按本条判；A、B 都是可指认的具体物件时（"冰箱里没有可乐，只有啤酒"）按事实陈述放行。
   - "不在A，在B"一类，以及"其实/恰恰"接在否定侧之后的自我对照（"他不是不在乎，其实是累了"），也按本条候选处理。
   - "没有A，只是/只有B" 若 A、B 都是主体的动作（说话、回头、加快脚步这类），不是在陈述事实：删掉"只是/只有"，把两个动作连起来写（"他没有说话，只是拉过她的手"→"他没有说话，拉过她的手"）。
   - 典型病灶：❌"这不是一次普通的版本更新，而是一次范式转移。"（没人主张过"普通更新"）→ ✅"这是一次范式转移。"
   - 典型病灶：❌"这不是节俭美德的回归，纯粹是钱包在做理性选择"（没人主张过节俭美德回归）→ ✅"这是钱包在做理性选择"。
   - 肯定面不得超出原句 B 的范围："不是A而是B"不能改成"不只是A"（那样把否定换成了程度限定），剩余部分须完整成句。
    - 清理豁免：否定侧是文体/写法判断（词表见 N14）时，否定面是作者的文学判断，保留。
R2 概括替代已有具体（判断类规则）：同段邻段就写着具体数值，却用"显著提升/大幅增长/明显改善/大量/众多"概括。生成时用平实动词，不许编数字、来源或案例。清理一律不改这类概括词，也不把同段数字嵌回原句；"完成了对……的优化/实现了……的提升"这类名词化写法同样原样保留。
R3 冒号滥用：(1) 提示语＋冒号（"一句话总结：/核心是：/原因如下：/本质上：/关键在于：/直接给答案："），删掉提示语，直接陈述。
   - 句首提示语可直接删；句中提示语先复核，确认删掉不丢信息再删。
   - (2) 标题冒号或破折号后半句出现材料不支持的口号、对仗或转折判断（判断类规则，"主流方案：简单但不随意"）。右半是否受材料支撑须通读上下文判断。
   - 不改：小标题内的冒号，右半是描述性标签（"部署：三步走"）时；冒号前那句话没有内容、只用来引出列表时（"我见过的几种典型场景："后接列表）。
R4 叙述破折号：叙述中破折号右侧承担解释、列举、同位、因果、补充或揭晓的，一律不用破折号；信息有必要不等于破折号有必要，逐处换成完整句或常规标点，不删信息。
    - 按形态逐处判断，不设数量配额。揭晓是右侧把前句没说出的原因或答案补上（"他忽然明白了"后接"钥匙一直在锁眼里"），按本条改成完整句。
    - 例外：破折号用于制造断裂而非接解释时不算病灶。台词被打断、思路中断、句子没说完、时间或场景硬切，这几种右侧悬空或另起一行，不承担解释、列举、同位、因果、补充、揭晓这六种关系，原样保留。
R5 序数词通篇编号小标题：同一层级的小标题以"一、二、三/第一、第二"编号且连续 ≥3 个，而各节标题没有各自的内容。生成时，这一节确实有独立内容就可以编号，不为排版连编空标题。清理不改已有编号。
   - 文学平行结构与清单段落同构率高，不按本条判。
R6 翻译腔（判断类规则，只认五种，生成与清理都改）：(1) 过长前置定语（修饰超十五字或"的"字连续三个以上）；
   - (2) "当……时"前置从句；
   - (3) "对于……来说"话题壳；
   - (4) "然而/此外/与此同时"在同一段或相邻段反复领起全句，形成每段一个路标的节奏；
   - (5) 空洞对冲语："从某种程度上说/在某种意义上/不得不说"不改变信息强度，删掉。
   - "这意味着/这表明"复述前句：生成时不写；清理原样保留。
   - 删掉的是语法成分，不是信息。
R7 装饰性喻体：(1) 拟人化模板：像/相当于＋理想化职业角色，或像/相当于＋系统、机械、自然类的固定比喻（智慧的导师、永不疲倦的审查员、交响乐团、精密钟表、引擎、灯塔）。裸名词（"数据引擎""灯塔项目""规则引擎"）是术语不是比喻，按 N4 原样保留，不按比喻处理；
   - (2) 句末短比喻小尾巴（"，像门轴"）；
   - (3) 用滥的比喻：不产生任何具体感知的比喻（"像溺水者抓住浮木""像一潭死水""像受惊的小兽""像安抚一只炸毛的兽"这一类）。
   - 普通单处明喻不逐处改；(2) 不单独处理，只在同一段两处或连着几段收句都用它时把这几个分句改掉；(1)(3) 出现一处就删掉或改变喻体。
   - 喻体有没有新增信息，看能不能说出具体质感（材质、粗糙度、温度、重量、气味或具体形态）；说不出质感的按 (3) 处理。细节见 `references/fiction.md` B3。
R8 起手式（句首）："说白了/说穿了/简单来说/简单说/先说结论/说到底/归根结底/综上所述/由此可见"。
R9 顿号罗列过密：一个分句内 ≥3 个顿号（即 ≥4 项并列）。具体名词枚举（人名、地名、店名、物件）、法规条目、配置项与操作步骤照抄；只有空泛同义堆叠才改写或概括。
R10 空降宏观开场：句首"在当今/在……时代（背景、环境）下/在……的今天/随着……不断发展（演变、进步、前进）/众所周知"且不含具体背景信息。
    - 起手语承载真实背景（人物、时间、数据、事件）时，删掉空话、留下信息。

## 二、N 层：防误杀白名单（两种模式都适用）

| 编号 | 特征 | 为什么不动 |
|---|---|---|
| N1 | 步骤词"首先/其次/最后" | 承担真实顺序指代 |
| N2 | 问句、设问、反问、问句小标题 | 常见写法，删问句只会更假 |
| N3 | 机制解释比喻 | 有助于理解；与 R7 的分界：喻体在讲原理的是解释 |
| N4 | 工程术语与业务实词（幂等/解耦/闭环控制/赋能/中台/接口） | 术语按原词写，不因业务语境同义替换 |
| N5 | 句长段落自然起伏 | 不为制造节奏调句长、拆段落 |
| N6 | 长距指代与必要重复 | 不避讳重复技术名词，不为躲重复生硬造词 |
| N7 | 被动句、名词化、规范复句 | 正常书面语，不盲目改平 |
| N8 | 句内同构排比（"提升效率，降低成本，优化体验"） | 常见写法，不按句间重复判 |
| N9 | 比喻本身、比喻起段 | 常见写法；禁区以 R7 列名形态为限（拟人化模板与用滥的比喻出现一处就改，句末短比喻看同段与连段） |
| N10 | 反复写全称、少用代词 | 正常写法 |
| N11 | 类型文惯例生理反应（拼杀时咬紧牙关、坠崖前抓住岩石、血顺着额角流下来一类） | 类型文的常态笔法；风格文档或用户范文支持时按作者保留。本条不覆盖 B5–B7 词表点名的写法：词表点名的按词表判，N11 只管没被点名的反应 |
| N12 | 歌谣、誓言、叫名字、口头禅的有意重复出现 | 重复是结构需要，不按 B7 的同词回环判 |
| N13 | 行内引号内的他人原话、术语强调与用户提供的范文 | 用词不改 |
| N14 | 文体与写法判断词（写实、煽情、说教、铺张、留白、炫技） | R1 被否定的那一侧是这类词时，被否定的内容保留 |
## 三、清理边界

频率原则：比喻密度、剧变副词等上限按"不超过"执行，不设配额下限。

用户递来成文要求清理时：
- 改完逐句对原文：每句的实义要么留在改稿里，要么能在核对时说明为什么能删。用户要求压缩时按用户给的比例办。
- 命中基本即可改；需要判断才能定的先复核，确认是纯病灶才改，否则保留；候选清单不输出。fiction 清理没有这一层：词表命中（B4/B6/B8 等）按本节「删除授权边界」复核后处理。
- 第一纪律：不丢信息。病灶词换掉，空壳拆掉，信息放回原处。删掉"说白了"后，其后分句必须完整保留（❌"说白了，这个告警从一开始就没人当回事。"删后整句消失即违规；✅"这个告警从一开始就没人当回事。"）。R1 改写里保留下来的肯定侧（"而是B"）、以及承载信息时后置的否定侧（"并非A"）都承载信息，删掉就是违规。
   - R1 回读：否定侧排除了一种具体可能时，改写稿必须仍能读出这个排除项。空泛否定删掉后只剩肯定侧，不放回。
   - 常见病灶：步骤词（N1 保护）、权限模型、赋能闭环等实词整句被删掉。
- 对话层规则禁用：客服式开场、问什么答什么属于写作偏好，强加于他人文章即构成篡改。
- 未命中规则的文字逐字保留。每处改动对应一条编号；有哪一处指不出编号，就撤销那一处。整篇一处改动都指不出编号时，原样交回整篇，不要为了显得干了活而改动。
- 等价改写不算清理：把"赋能"换成"支撑"、把"完成了数据中台的搭建"压成"搭建了数据中台"两边信息相同，改动没有依据，原样保留。
- 商业黑话不单独删词：带具体对象、动作或结果的短语（"为上层应用赋能"）更不在删除范围。本条不另开整句删除授权。
- 不许新增，也不许丢：每个实词能溯源到原文；姓名、数字、日期、引语、来源、因果不增不删；限定词与让步（"可能/通常/据说"）强度不变，"可能提升"不得改成"提升"。
- 标题层级、章节段落顺序、列表、表格、代码块位置原样保留。只有 B5/B6/B7 的纯套话（"一股莫名的情绪涌上心头""他猛地一僵""许多年以后他才会明白"）在确认该句除套话外没有情节线索、真实力度或速度、且删后句意完整时，属规则授权删除；承载这些信息的保留。B8 问答乒乓删轮次的授权见下文「fiction 清理规则」。其余整句删除需用户同意，句内修改不另行说明。
- B7 同词回环、生硬点题、预告式钩子的触发语是句子主谓框架（"他不知道的是""所谓陪伴不过是"），只删触发词短语，不整句删；整句就是这句触发语的，按上一条处理；整句重复可整句删。
- 删多少看这句除了套话还有什么：只剩主语（人称或"年轻人"这类短指称）就连主语一起删；还有动作、物件或因果，就只删套话本体。
- 默认只交改写后的正文，不附判定链、命中清单、评分或自我评价；用户追问改动时再说明。诊断模式（用户明确只要求指出问题、不要改写）不适用本条：那一模式交付的就是"命中处＋编号＋一句理由"。
- 引号形态照原样：清理他人成稿时一个引号都不动，ASCII 直引号不改成全角，全角不改成直角。
- 模糊归因（"有研究表明/业内（普遍）认为/专家指出/不少用户反馈"）在清理模式下原样保留。生成时不把没有来源的结论写成事实；不得把无源数字写成确定事实，也不得把"40%"弱化成"很多"、把"未来十年"缩成"未来几年"。
- fiction 成稿清理：按下面「fiction 清理规则」执行，R 层只带入下节列明的条目，C 层不带入。

### fiction 清理规则

- 风格文档优先：按 `references/fiction.md` 零、基本原则执行，句法、标点、用词与节奏偏好以风格文档为准。
- 带入的规则：R4 破折号、R7 比喻、R8 起手式 ＋ R1 翻案腔、R6 翻译腔五种。R5 清理不改已有编号，不带入。
- 小说页 B4–B9 的删除与降低频率判据同时适用；不改写角色台词，叙述层按原判据处理；B8 全部子项仍按原判据检查（对白行计入）；句首代词连珠/句内主语复现/装饰标签按删除授权边界复核后改。
- B5/B6/B7 的生成改法不用于清理：只删纯套话，不补写新的动作、神态、身体反应或氛围。风格文档或用户范文支持时依范文保留；N11 不援引，它不覆盖这几节点名的词表项，点名的按词表判。
- 对白标签：不补标签，分不清是谁在说时保留原标签。装饰标签承载的音量、语气或言语行为无法由对白内容、动作或上下文读出时保留；删后仍能看出谁在说且不丢信息，才删。
- fiction.md 取用范围：取基本原则、第一节的视点与镜头要求、B1–B9；叙事工法、交付自检、叙事工法范例是写作期内容，不带入。按工法改他人成稿等于重排作者的节奏与结构。
- 不带入：R2 概括替代已有具体、R3 冒号滥用、R5 序数词编号、R9 顿号罗列、R10 宏观开场与 C 层软建议。虚构文体的段落节奏、列举密度与人物口吻自有其法，照通用判据清理会误改。
- 删除授权边界：词表命中先作候选，确认删掉不丢信息才下刀。B4 那七个动作副词是默认值，"微微/轻轻/缓缓"修饰动作时不额外说明任何差别，按 B4 直删；同一个词陈述客观状态时（"微微发烫的杯壁""极慢的车流"）说的就是这个状态，保留。其余词表按"该词是否承载具体的力度、速度、音量、语气、言语行为或情节线索"判，承载就保留（对白标签带出读不出来的音量或语气时，按上面「对白标签」一条处理）。删后句意须完整，对白标签还须删后仍能看出谁在说。整句及以上的授权见本节上文。
- 拆段并段同禁：段落数量与顺序原样保留，不把一段拆成几行，也不把几行并成一段。两处例外：B8 问答乒乓的去留按下一条处理；B8 句首代词连珠按 fiction 的改法并成一句。
