# Fiction 叙事创作与文学张力指南

本指南专用于故事、小说与叙事场景，消除 AI 常见的油腻感与模式化代偿。

---

## 一、 设定守恒与正向写作技法

1. **事实与设定守恒（最高优先级）**：
   - 严格遵循用户给定的世界观设定、角色体质与人设事实。
   - 凡人遵循肉身生理代价（疲惫、伤痛、体温、物理阻力）；超凡存在遵循认知异质感与存在反差。
2. **文风自洽与零会话污染**：
   - 规则适用于所有题材（奇幻、科幻、历史、现实主义、都市），正文严格保持沉浸在场。
3. **纯动作感官先行**：
   - 只写角色此刻直接感知（视/听/触/嗅）与即时行动动机，不写不在场信息。
   - 动作描写必须包含物理因果、重量、阻力与环境微互动，不退化为孤立的散碎短句报菜名。
4. **松紧交替与留白**：
   - 紧张/暧昧/恐惧/受伤场景放慢镜头，拆解微动作；日常过渡大步流星，不事无巨细流水账。
   - 留白省略多余解释，但主干指代、施受关系与因果清晰闭合，不留悬空代词。
5. **段落长短参差**：
   - 段落长度参差错落，允许单句成段，打破匀速水波式的三句一段节奏。
6. **猜测代替提问与禁止式暴露**：
   - 角色对另一人的观察可以是一串动作猜测，对方不正面解释，作者更不跳出补齐；
   - 往事以“刻意回避、不愿想那件事”的形式出现，回避比大段回忆闪回更具张力。
7. **视角切换自然过渡**：
   - 视角切换或转场时，通过声音、视线或人物动作自然带入，避免突兀生硬的上帝视角瞬移。

## 二、 风格标杆（学姿态，不学句子）

### 1. 人物动作（纯动作序列，无心理推测）
> 他用两手攀着上面，两脚再向上缩；他肥胖的身子向左微倾，显出努力的样子。这时我看见他的背影，我的泪很快地流下来了。我赶紧拭干了泪。怕他看见，也怕别人看见。我再向外看时，他已抱了朱红的橘子往回走了。过铁道时，他先将橘子散放在地上，自己慢慢爬下，再抱起橘子走。到这边时，我赶紧去搀他。

*【解析】：全段全是动作和感官，情感由动作本身传达，一个比喻都没有。学它的“劲儿”。把“像X一样”的冲动替换为：写出那个人具体做了什么、身体哪个部位怎么动了、发出什么声音、触感是什么。*

### 2. 景物修辞（比喻质地：各管一事、具象生活实物以实喻虚）
> 他靠纱窗望出去。满天的星又密又忙，它们声息全无，而看来只觉得天上热闹。一梳月亮象形容未长成的女孩子，但见人已不羞缩，光明和轮廓都清新刻露，渐渐可烘衬夜景。小园草地里的小虫琐琐屑屑地在夜谈。不知哪里的蛙群齐心协力地干号，象声浪给火煮得发沸。几星萤火优游来去，不象飞行，象在厚密的空气里漂浮，月光不到的阴黑处，一点萤火忽明，象夏夜的一只微绿的小眼睛。

*【解析】：数一下：五个比喻。月亮的轮廓、蛙声的质地、萤火的动态、萤火的光点，各管一件事，没有两个在修饰同一属性。喻体全是具体物：女孩子、煮沸的水、小眼睛。所以密集不腻。写崩比喻通常是因为喻体空泛（“像某种说不清的情绪”）加反复夸同一件事。*

### 3. 场景动线（打碎景物砖：人动景现、视线递进）
> 伦敦的冬雾，真的提前保卫这古城了吗？早晨起来，把毛毯一卷，连同草垫抱到堆房里。上楼时，觉得很冷。用木棍拨开窗上的黑帘，外面是一片凄迷的灰雾。不但没有了后街伊顿路教堂的尖楼，竟连后园的梨树也依稀只剩条黑影。正在发怔时，一声味噢，一个躜动，我们的狸花猫坐在沙发背上了。它怯生生地了了我一眼，就缩着四条腿，把身子蜷得像个鼓肚子花瓶，对着灰雾出起神来。

*【解析】：看景是怎么被打断的：卷毛毯、抱草垫、上楼、觉得冷、拨帘子，人先动起来，才看见雾；雾看到一半猫跳上沙发，视线被猫抢走，猫再看回雾。景物从没连续独占超过两句。不要先描完环境再让人物出场，那是一块景物砖。两段的顺序按视线逐渐辨认的过程展开：先一片混沌，再显出轮廓，最后认出是什么。*

## 三、 核心心智：摄影机视点在场与实体阻力

1. **摄影机视点在场与限知叙事（严禁作者跳出镜头读心）**：
   - **核心逻辑**：小说必须从当前视点角色的眼睛、耳朵与身体往外写，而不是作者站在全知上帝视角替角色做心理总结。
   - **严禁作者跳出镜头读心与贴标签**：
     - ❌ 严禁作者直接贴心理标签：“他表面平静实则内心波澜起伏”、“他知道这是个陷阱”、“他内心其实十分愧疚”、“像是在组织一句妥当的回答”。
     - ✅ 还原为动作、神态与角色的主观感知：写对方指节按在桌上的力道、视线的落点、呼吸的轻重；推测也必须保留视点角色的感知距离（“他像是在等一个台阶”、“仿佛刚才那句话没入耳”）。
   - **严禁上帝视角剧透**：镜头全程锁定在视点角色的物理感知半径内，严禁出现“你/他不知道的是……”或脱离场景的人生哲理大总结。

2. **拒绝同词回环的伪深沉套路（“很A……A到……”）**：
   - **核心逻辑**：不限制文笔与正常比喻，只禁止用缺乏现场细节的句式模板制造廉价的深沉感。
     - ❌ 严禁同词回环：“看了很久，久到尘埃落定”、“走了很远，远到看不见尽头”、“伤得很深，深到麻木”。
     - ✅ 落地为具体物理变化：写时间推移，写环境与客观事实的变化（烛泪凝固、窗外雨声渐歇、茶水放凉、对方换了支撑的重心），让程度与时间在客观事实中自然流淌，不靠套话空转。

3. **实体阻力与三大物理张力工具（正向落地）**：
   - 当需要表现角色心绪波动、试探靠近或对抗博弈时，优先使用三大物理事实工具替代虚空推测与抽象情绪：
     ① **空间距离位移**：靠近半寸、挪开一臂、侧身避开、退到石阶边缘；
     ② **物理阻力与微触感**：粗糙石面、衣料摩擦、温差落差、脉搏撞击指腹；
     ③ **视线投射与动作停顿**：视线停在某处数息、手抬起停在半空未落、指尖收拢后展开。

4. **比喻极度克制与质地判据（重质地与具体物，严防空泛烂喻）**：
   - **核心原则**：重在喻体质地而非死板数数，严防比喻水肿与同属性反复打比方；喻体务必具体可感（如夏夜标杆中的“女孩子”、“煮沸的水”、“微绿的小眼睛”）。
   - **功能比喻（放行） vs 装饰烂喻（坚决封杀）**：
     - ❌ 装饰烂喻（坚决封杀）：喻体与本体无共享属性、无机制阐释的虚空挂件（如“眼神像深潭”、“像受惊小兽”、“像随时折断的弦”、“像某种说不清的情绪”）；
     - ✅ 功能比喻（合法保留）：承载空间氛围、关键意象或感官通感的贴切具体比喻（如“像一轮被掐去焰芯的月”、“清晰得像石子落水”、“像煮沸的水”）。

5. **彻底封杀翻案腔（严禁先否定再肯定，只留肯定）**：
   - **核心逻辑**：严禁自立靶子搞“先否定、再肯定”的说教（「不是……而是……」、「其实不是……只是……」、「不仅是……更是……」、「与其说……不如说……」）。
   - **操作方法**：把前半句的否定和转折词全删掉，只保留后面的肯定事实：
     - ❌ 严禁多重否定排除：`不是A，也不是B，只是C` ➔ ✅ 只留肯定：`是C`。
     - ❌ 严禁声音动作否定排除：`不是咳，不是抽气，只是翻了个身。` ➔ ✅ 只留肯定：`他翻了个身。`
     - ❌ 严禁状态否定排除：`不是熄灭，而是暗能沉入深处。` ➔ ✅ 只留肯定：`暗能沉入深处。`

6. **动作服务于情境**：
   - 避免无意义的套路动作堆砌，让肢体动作、呼吸与生理反应自然融入场景博弈，不设机械死锁。

7. **台词人设主权**：
   - 台词受人设主权保护，必须且仅服务于当前博弈动机与角色性格，打破连续 3 轮以上毫无阻碍的一问一答回合制拆招。

8. **破折号科学限频（≤ 2 处/千字）**：
   - 严禁滥用破折号制造刻意揭晓与后置补丁（如“答案很简单——专注”）；改用常规标点自然成句。
   - 叙述层破折号仅用于真实的急促断奏，全篇严格限频（每千字 ≤ 2 处）；台词抢白打断与拖音不受限。

9. **禁止结尾向读者说教**：
   - 故事自然收束，结尾不论收在对白、动作、余韵还是开放式停顿皆可，不强行限定结尾形式；
   - 坚决封杀：作者出戏向读者发散宏大誓言、时代命运、人生哲理或感悟大总结（严禁：`一个从未被……的人，要用多少力气……`、`他终于读懂了命运的真谛`）。

10. **禁令冻结**：
    - 现有红线清单之外，坚决不再追加任何未经机器正则实测支持的细碎句子禁令。不可机械化判定的文风与格调，全部走正向范文与语感引导。

## 四、 叙事描写硬替换映射表（动态原则，严防新套路化）

> **【防新模板声明】**：本清单为举例说明，核心是提炼现场物理反馈；同一套路换任何同义词仍属违规；✅ 列出的是物理落地原则，**严禁机械死记或直接套用固定句式配件**（如滴漏、数息、一盏茶）；必须根据具体情节提炼独特的现场物理反馈。

| ❌ 严禁出现（作者讲戏与条件反射） | ✅ 必须替换为（具体客观物理事实与视点观察） |
| :--- | :--- |
| **“像是在组织回答/像在决定/像是想推开”** | ➔ **写客观停顿：“她视线停了片刻，没有做声。” / “指腹停在石面上。”** |
| **“像是在确认什么证据/像是想确认什么”** | ➔ **写具体视线与动作：“她垂着眼，视线落在那处伤痕上。” / “指尖探了探脉息。”** |
| **“像怕碰坏/像怕惊散（作者视角脑补）”** | ➔ **写动作受阻与延时：“动作放慢，停在半空。” / “手悬了一息才落下。”** |
| **“看了很久，久到……” / “过了很久，久到……”** | ➔ **写客观事件推进：“水声停了。” / “雨势渐歇。” / “烛火晃了两下。”** |
| **“不是咳，不是抽气，只是……”** | ➔ **直接陈述事实：“她听见布料翻动的轻响，是翻了个身。”** |
| **“不是熄灭，而是……” / “不是……而是……”** | ➔ **正面给判断：“暗能沉入深处。”（严禁虚立靶子再推翻）** |
| **“眼神像深潭/像受惊小兽（虚空烂喻）”** | ➔ **写具体视线与神色：“视线偏开一瞬。” / “她别过头，没有接话。”** |

## 五、 全局通杀红线（输出前逐句扫描过滤）

1. **绝对禁字与硬红线**：
   - 叙述层严禁字样：`久到`、`不是.*只是`、`不是.*而是`、`你不知道的是`。
   - 警惕装深沉时间感：除历史追忆与宏大回溯体外，即时叙事中禁用“多年以后他才会明白”等全知俯视。
2. **比喻质地与标点限频**：
   - 坚决杜绝空泛装饰烂喻，比喻务必落在具象生活实物上（以实喻虚）；叙述层破折号严控在每千字 ≤ 2 处以内。
3. **成文清理保护原则**：
   - 润色时严格信息守恒，坚决杜绝篇幅缩水塌陷（保真 80%~100%）。

## 六、 成文清理与保真边界

在对成稿小说执行润色与去 AI 味清洗时：
- 严格遵守 `references/polish.md` 中的信息守恒原则与篇幅保护（80%~100% 篇幅）；
- 严禁随意删除实质剧情、对白与博弈细节，不得将长文压缩为梗概；
- 仅做句内去味、去除多余装饰挂件烂喻与破折号限频平准化处理。

## 七、 成稿自省、四遍复审与整体通读检查协议（交付前必经回路）

成稿后，在输出前必须在内心完成三层递进式的自我审查回路：

### 1. 深度自省（认知与姿态纠偏）
- **我是不是在“替角色讲戏”？**
  - 检索文中是否有作者脱离镜头脑补的心理推测（如“像是在组织语言”、“像怕碰坏”、“像是想推开”）；
  - 角色的动机必须由物理动作、视线停顿与对白受阻自然流露，严禁作者下场当“画外音解说员”。
- **我是不是在“向读者说教”？**
  - 检查高潮与结尾处，是否冒出了假大空的感悟大词（“这一刻他终于明白生命的真谛”、“这不仅是……更是……”）；
  - 镜头必须死死钉在现场，写完客观物理事实即止。
- **台词受人设主权保护**：
  - 台词必须且仅服务于角色性格与当前博弈动机。

### 2. 定点专项复审（显微镜式逐项核验）
- **第一遍·抓标点与停顿**：检索全篇「——」，核对叙述层是否被滥用为后置揭晓或煽情停顿（如“——那是”），改用常规标点；叙述破折号压在每千字 2 处以内，台词打断拖音放行。
- **第二遍·抓比喻质地与空泛度**：检索全篇「像/仿佛/宛如」，坚决拔除无共享属性的 AI 装饰烂喻（眼神像深潭、像受惊小兽、像随时折断的弦），改写为具象生活实物或物理事实（位移、阻力、温差、微触感）；严禁对同一属性连续堆叠比喻。
- **第三遍·抓翻案腔句式（不杀正常词）**：核验有无自立靶子的“先否定再肯定”（如「不是A，而是B」/「其实不是A，只是B」）；砍掉多余否定，直接正面陈述肯定事实；正常表示范围或程度限制的“只是/但”完全放行。
- **第四遍·抓同词回环伪深沉（“很A……A到……”）**：检索筛除“看了很久，久到……”、“走了很远，远到……”、“伤得很深，深到……”等句式；时间推移与程度必须落地为客观物理变化（雨声渐歇、茶水放凉、换了支撑重心），严禁同词空转。

### 3. 整体检查（宏观呼吸与质感验收）
- **禁止出戏向读者说教**：故事自然收束，结尾不论收在对白、动作、余韵还是开放式停顿皆可，严禁作者出戏向读者总结时代命运或人生大道理。
- **视角切换自然过渡**：换视角时通过环境、视线或动作自然引出，避免突兀生硬的上帝视角瞬移。
- **语流节奏长短参差**：是否存在相邻两三句连续复用同一句法骨架（主谓宾，主谓宾）像填表？有没有适当的单句成段形成语言顿挫？
- **信息守恒与篇幅保真**：润色时是否坚守 80%~100% 篇幅，严禁将长篇压缩为梗概，严禁脑补新剧情。
