# 文本层规则详情（B1–B11）

SKILL.md 的随行参考：核心页给触发标记与一句话改法，命中规则后来这里核对改法、示例与边界。

B1–B11 的触发标记与反清单依据外部对照研究（629 篇约 283 万字的人机对照，见 README 致谢与 docs/porting-map.md）整理而来，置信全部为 [实测-上游]，本项目未独立复核。

**B1 翻案腔** [实测-上游][机械]
触发：`不是X而是Y`、`不仅仅是X而是Y`、`不在于X而在于Y`、`与其说X不如说Y`、`看似X实则Y`、`你以为X其实Y`，以及虚立没人主张的误解再推翻
改法：搜"而是""其实""恰恰"，逐处核对被否定的观点是否真存在于语境。不存在→删否定留肯定；存在→保留原句——真修正不是翻案腔，清理模式不动（回归门 A4 实证：强行换句式必误伤人类成文）

> ❌ 真正的瓶颈不是技术，而是耐心。 → ✅ 真正的瓶颈是耐心。
>
> ❌ 我们需要的不是更多的数据，而是更好的判断力。 → ✅ 我们需要的是更好的判断力。

不改：角色台词内

**B2 概括盖住已有具体** [实测-上游][需判断]
触发："显著提升/大幅增长/明显改善/大量/众多"断言而具体数值就在同段邻段；"完成了对…的优化""实现了…的提升"
改法：把已有的具体值提到概括词位置；原文没数据时只恢复动词

> ❌ 新系统实现了效率的提升。处理时间从两小时缩到四十分钟。 → ✅ 新系统把处理时间从两小时缩到四十分钟。
>
> ❌ 团队完成了对流程的优化。 → ✅ 团队把流程改顺了。（原文没给数据，只恢复动词）

与 N11 的分界：行业大词（赋能/闭环/底层逻辑/至关重要）不属本条，那是中文商业写作正常用词；本条只抓概括表述盖住同段已有的具体值。

反向硬约束优先于本条：不为显得具体编造数字、来源、姓名、日期、案例。每个具体值指得出出处（用户给的、上下文有的、明确标为假设），指不出就换回概括，宁可保持抽象，不得编造

**B3 段首零回指评论** [实测-上游][机械]
触发：非首段以"听起来/看起来/值得注意的是/更重要的是/关键在于/问题在于"开头，整句无"这/那/其/此/上面"回指
改法：通常加一个"这"字
优先级：同一处同时命中 B4（提示语＋冒号）或 B10（起手式）时以删除为准，本条不适用——删掉提示语后段首评论已不存在，加回指无从谈起

> ❌ 听起来像一条功能描述，其实底下换掉了一样更根本的东西。 → ✅ 这听起来像一条功能描述，其实底下换掉了一样更根本的东西。

不改：首段（无上文可指）；对话引语内部

**B4 冒号滥用** [实测-上游][机械]
触发①提示语引出：冒号前是"一句话总结/核心是/关键在于/原因如下/本质上"。②空转句引列表：一行以冒号结尾、下接列表，删掉信息不减
改法：提示语不带信息就删；承接上文的留半句换标点。空转句改成有内容的判断或删掉让列表接上文。不得删除列表项

> ❌ 一句话总结：这个方案成本太高。 → ✅ 这个方案成本太高。
>
> ❌ 我见过的几种典型场景： → ✅ 这几种场景我都见过。

不改：引出人物原话；小标题内冒号；句中总说分说；网址代码

**B5 破折号揭晓** [实测-上游][需判断]
触发：破折号制造停顿揭晓（"答案其实很简单——专注"）或插非必要补充
改法：写完整句或换逗号句号；破折号只留话没说完和真悬念
判读：删掉破折号后半句会丢信息的，是必要补充，不触发。本条不设数量上限，只认触发标记：数量上限可被规避，触发标记不会

> ❌ 答案其实很简单——专注。 → ✅ 答案是专注。
>
> ❌ 他找到了一条路——一条所有人都忽略的路。 → ✅ 他找到了一条别人都没注意的路。

**B6 序数词通篇编号小标题** [实测-上游][机械]
触发：小标题以"一、二、三/第一、第二"编号且连续 ≥3 个
改法：删编号留文字，措辞顺序层级不动

> ❌ ## 一、先找出模糊在哪里 / ## 二、把需求写成模块 / ## 三、合成第一版 prompt
> → ✅ ## 先找出模糊在哪里 / ## 把需求写成模块 / ## 合成第一版 prompt

不改：正文顺序词；指代性编号（"见第三条"）；Markdown有序列表；仅一两个编号

**B7 相邻句结构同款** [实测-上游][需判断]
触发：相邻 ≥2 句逗号数相同、成分顺序相同、长度接近，典型"主语＋动词＋宾语，＋补充说明"连发
近似动作：相邻两句逗号数差 ≤1 且长度接近 → 先标记，再复核成分顺序；同款才改
改法：打散其中一句：合并、拆分、换语序均可；只动句内，不动段落，不删信息

> ❌ 这个功能上线后用户反馈很好。团队的开发效率提升明显。下一步的优化方向已经确定。
> → ✅ 这个功能上线后用户反馈很好，团队开发效率也提升了。下一步优化什么，已经定了。

边界：只管句间重复，句内同构排比（"提升效率，降低成本，优化体验"）人类用得更多，不得修改；不得为制造节奏调整句长或拆分段落（离散度实测无差异）；清单式段落（操作步骤、并列条款）本来就该整齐，不改

**B8 翻译腔（五种以外不认）** [实测-上游][机械]
①过长前置定语：中心名词前修饰超十五字或连续两个"的" → 拆成两个分句
②"当……时"前置从句 → 删"当"和"时"让从句作前一分句；确需标示时点的除外
③前置话题壳："对于……来说/就……而言"而后句本就以它为主语 → 对象提进主语位删壳；需限定讨论范围的除外
④句首连接词当路标："然而/此外/与此同时"领起，尤其连续段落 → 移到主语后或换"不过"；论证确需路标的除外
⑤"这意味着/这表明"复述前句 → 并入前句；给出新结论则保留

> ❌ 这是一个能够让团队在不增加人力的情况下显著提升审核速度的工具。 → ✅ 这个工具能显著提升审核速度，不需要增加人力。
>
> ❌ 当所有人都能用 AI 写文章时，内容本身就不再是竞争优势。 → ✅ 所有人都能用 AI 写文章，内容本身就不再是竞争优势。
>
> ❌ 对于早期团队来说，招人是最难的事。 → ✅ 早期团队最难的事是招人。
>
> ❌ 然而，这个方案并不适用于所有场景。 → ✅ 这个方案其实不适用于所有场景。
>
> ❌ 留存率涨到了 72%。这意味着产品找到了 PMF。 → ✅ 留存率涨到 72%，产品找到了 PMF。

"以一种……的方式""扮演……角色""使得……能够"不在本条范围，读着生硬也保留。术语、公文固定表达不受影响

**B9 拟人化喻体** [实测-上游][需判断]
触发：像/相当于＋一个/一位＋职业角色（导师、秘书、审查员……）带褒义修饰或后接"不仅……更……"
改法：换成这东西实际做了什么

> ❌ 它就像一位智慧的导师，不仅传授结论，更传授看待世界的多元视角。 → ✅ 它不只给结论，也讲看待问题的不同角度。

比喻本身不是AI痕迹，禁区只限理想化人格模板（智慧的导师、永不疲倦的审查员、全能的助手）。具体的人带具体本事是正常写法："像个老师傅，凭经验拦住七成误操作"不动

**B10 起手式** [实测-上游][机械]
"说白了""说穿了""先说结论"，删掉，直接给判断

> ❌ 说白了，这个项目没有足够的预算。 → ✅ 这个项目预算不足。

**B11 顿号罗列过密** [实测-上游][机械]
触发：一个分句内 ≥2 个顿号串 ≥3 项并列
改法：能概括就概括（"采集、存储、展示"→"从采集到展示"）；必须保留时改变其中一项句法

> ❌ 采集、存储、展示。 → ✅ 从采集到展示。

不改：法规条目、配置项、财务科目等必须完整列出的；Markdown列表内部。不为处理本条牺牲准确度
