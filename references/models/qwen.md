# Qwen 写作特征与适配参考

针对 Qwen（通义千问）系列模型在中文叙事中的常见表达偏好，提供针对性的写作参考与建议。

---

## 一、 常见写作倾向与建议

### 1. 避免章尾生硬点题与升华
- **常见现象**：
  在情节收尾时，容易滑入反思与人生大道理（例如：`那一刻，他终于明白了信任的代价……`、`这或许就是命运最好的安排`）。
- **调整建议**：
  结尾停在未完成的动作、人物的当下抉择或新发现的物理证据上，避免在末段留下抒情总结。不写“那一刻/他明白/他懂得/这正是”。

### 2. 避免千篇一律的温情大团圆
- **常见现象**：
  在多角色矛盾中，倾向于让所有人最终“达成默契与谅解”，消解了原本的真实代价。
- **调整建议**：
  故事结束时允许保留未愈合的裂隙、道德两难或现实残局。

### 3. 避免滥用突发副词（“骤然/猛然/轰然”）
- **常见现象**：
  在角色肢体接触或紧张情境时，容易频繁插入“骤然收紧/猛然一僵/身形一震”，破坏了物理质感。
- **调整建议**：
  叙述中尽量不用“骤然/猛然/轰然/猝然/猛地”。改用写实的身体受力与沉降描写（如：`肌肉收紧`、`指节压白`、`整个人定住`、`力道沉下去`）。

### 4. 避免连续以人称代词打头
- **常见现象**：
  叙述复杂动作时，容易连续数句均以同一代词起笔（如：“你先把碗底……你重新倒盐……你拿布擦掉……你换了三块布……”），产生机械排比的填表感。
- **调整建议**：
  同一主体的动作尽量合并为连贯长句；第二句可由受力器物、动作本身或环境客体起笔（如：“碗底磕在木案上，重新舀上清水”、“粗布擦掉周围凝血”）。

## 二、 写作与检查要点

在输出最终正文前，Qwen 需扫描拦截：
1. [ ] 正文叙述层破折号是否严格为 0？（绝对禁止使用“——”制造停顿或补丁）；
2. [ ] 末尾三句话是否在总结人生道理、感悟或升华主题？（若是，整段删除）；
3. [ ] 是否强行给出了大和解式的结局？
4. [ ] 是否混入了“骤然/猛然/轰然/猝然/猛地”等网文电击副词？（若是，替换为骨骼物理滞后描写）；
5. [ ] 是否对齐了三大笔法范本（按范本 1 纯动作承载情感消除抒情升华，按范本 3 动线打碎抒情段）？
6. [ ] 全文核验是否存在连续以人称代词（他/你/她）打头的单句碎切与口吃？在第二人称长文中，必须多由器物受力、感官承接起笔，强制整合为“一主串多动”的连贯完整复句。
