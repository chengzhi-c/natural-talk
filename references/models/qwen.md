# Qwen 专项神经代偿指南 (Qwen Model Adapter)

本文件为 **Qwen（通义千问）宿主模型专用代偿协议**。针对 Qwen 系列模型在中文叙事中的底层神经偏好与写作病灶，进行定点压制与重构。

---

## 一、 Qwen 核心病灶与针对性药方

### 1. 章尾点题与升华成瘾（伪深刻升华）
- **病灶表现**：
  Qwen 擅长逻辑推进，但在情节收尾时，极易强行滑入反思与人生大道理（例如：`那一刻，他终于明白了信任的代价……`、`这或许就是命运最好的安排`）。
- **特供药方**：
  - **强制冷峻断章（5 类硬悬念钩子）**：结尾动作进行到一半遭遇阻断、或发现异常物理证据即停，严禁在末段留下任何抒情性结语；
  - **封杀心理总结句**：严禁出现“那一刻/他明白/他懂得/这正是”。

### 2. 伪善大团圆与温情和解通配符
- **病灶表现**：
  在多角色矛盾中，Qwen 倾向于让所有人最终“达成某种默契与谅解”，消解真实代价。
- **特供药方**：
  - **保留未愈合的代价**：故事结束时必须保留不可挽回的裂隙、道德两难或现实残局。

### 3. 网文突发电击副词惯性（“骤然/猛然/轰然”）
- **病灶表现**：
  Qwen 极易在角色肢体接触或突发情境时插入“骤然收紧/猛然一僵/身形一震”，以此廉价制造紧张感，破坏了物理质感。
- **特供药方**：
  - **封杀瞬发副词**：正文叙述层严禁出现“骤然/猛然/轰然/猝然/猛地”。
  - **物理沉降代偿**：改用骨骼重力沉降或迟滞受力描写（如：`肌肉收紧`、`指节压白`、`整个人定住`、`力道沉下去`）。

### 4. 连续主语连珠与代词填表感
- **病灶表现**：
  Qwen 在叙述复杂动作时，极易连续数句均以同一代词起笔（如：“你先把碗底……你重新倒盐……你拿布擦掉……你换了三块布……”），产生机械排比的填表感。
- **特供药方**：
  - **客体起笔与动作顺承**：禁止连续两句以上以同一人称代词起笔；第二句强制由**受力器物、动作本身或环境客体**起笔（如：“碗底磕在木案上，重新舀上清水”、“粗布擦掉周围凝血”、“换到第三块布，创口周围才露出来”）。

## 二、 Qwen 交卷前定点拦截清单

在输出最终正文前，Qwen 需扫描拦截：
1. [ ] 正文叙述层破折号是否严格为 0？（绝对禁止使用“——”制造停顿或补丁）；
2. [ ] 末尾三句话是否在总结人生道理、感悟或升华主题？（若是，整段删除）；
3. [ ] 是否强行给出了大和解式的结局？
4. [ ] 是否混入了“骤然/猛然/轰然/猝然/猛地”等网文电击副词？（若是，替换为骨骼物理滞后描写）；
5. [ ] 是否对齐了三大笔法范本（按范本 1 纯动作承载情感消除抒情升华，按范本 3 动线打碎抒情段）？
6. [ ] 全文核验是否存在连续以人称代词（他/你/她）打头的单句碎切与口吃？在第二人称长文中，必须多由器物受力、感官承接起笔，强制整合为“一主串多动”的连贯完整复句。
