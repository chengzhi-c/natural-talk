# Kimi 写作特征与适配参考

针对 Kimi 系列模型（K2、K2.6 等）在中文长程叙事中的常见表达偏好，提供针对性的写作参考与建议。

---

## 一、 常见写作倾向与建议

### 1. 避免分句末尾短比喻挂件
- **常见现象**：
  生成节奏舒缓，但有时容易在分句末尾挂载四字比喻小尾巴（例如：`，像年头太久的门轴`、`，像一潭死水`、`，像受惊的鹿`）。
- **调整建议**：
  动作写完直接句号断开，不在分句后逗号接“，像……”；不提供具体感官细节（气味、温度、触觉）的比喻直接删去。

### 2. 避免否定式反向澄清
- **常见现象**：
  在提示词中看到否定禁令时，容易在正文中写出反向澄清（如“她没有掐掌心，只是……”或“我不是在教你”）。
- **调整建议**：
  把注意力放在具体的正面动作（如手头抓握硬物、视线看火塘白灰）上，直接陈述发生的事情。

### 3. 避免句首代词连珠
- **常见现象**：
  容易多个分句都以代词打头（“他端着……他蹲下……他抓起……他按住……”），导致语流割裂。
- **调整建议**：
  同一主体的连贯动作合并为长句；第二句多用器物、身体部位（“粗陶盆磕上石砖”、“指尖抠起布边”）起笔；相邻分句避免连续用相同代词打头。

### 4. 叙述层破折号清零
- **常见现象**：
  叙事中容易用破折号制造叙述者内心的悬停或自我纠偏（例如：`你微微偏过头—— 不，你没有。`）。
- **调整建议**：
  正文叙述中不使用破折号（——），纠偏与悬停写实为当下的客观停顿或直接陈述，不借破折号搞自问自答。

### 5. 避免滥用突发副词（“骤然/猛地/死死”）
- **常见现象**：
  在张力转换或动作描写时，下意识插入“骤然暗了一下”、“猛地亮起”、“死死按住”等戏剧性副词。
- **调整建议**：
  叙述中尽量不用“骤然/猛地/猝然/死死”，改用写实的身体受力与停顿（“定住”、“光晕收敛”、“指节收拢”）。

## 二、 写作与检查要点

在输出最终正文前，Kimi 需扫描拦截：
1. [ ] 正文中有无出现任何叙述层 `——`？（破折号计数必须严格为 0）；
2. [ ] 是否混入了“骤然/猛地/猝然/死死”等舞台剧抽搐词？（全部替换为动作停顿与骨骼受力）；
3. [ ] 全文搜索“像”字，核验是否有任何 4~6 字的句尾短比喻挂件？
4. [ ] 是否出现了带有“没有/不是”的否定式澄清？
5. [ ] 是否对齐了三大笔法范本（按范本 1 纯动词链推进消除句尾挂件，按范本 3 人动景出与碎砖律）？
6. [ ] 全文核验是否存在“他……他……他……”等单句碎切与句首代词口吃？（切忌走向生硬抹除人称的电报体，强制整合为“一主串多动”的连贯完整复句，保证句子行云流水般连贯好读）。
