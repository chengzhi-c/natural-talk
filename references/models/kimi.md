# Kimi 专项神经代偿指南 (Kimi Model Adapter)

本文件为 **Kimi 宿主模型专用代偿协议**。针对 Kimi 系列模型（K2、K2.6 等）在中文长程叙事中的底层神经偏好与写作病灶，进行定点压制与重构。

---

## 一、 Kimi 核心病灶与针对性药方

### 1. 句尾塑料短比喻挂件癖（最顽固毒点）
- **病灶表现**：
  Kimi 生成节奏舒缓沉浸，但极度沉迷在分句末尾机械挂载四字比喻小尾巴（例如：`，像年头太久的门轴`、`，像一潭死水`、`，像受惊的鹿`）。
- **特供药方**：
  - **句尾硬着陆**：动作写完直接加句号，严禁逗号后接“，像……”；
  - **保留实体通感，删除纯修饰喻体**：凡不能提供新的物理信息量（气味、温度、触觉）的比喻，一律切除。

### 2. 负面词禁令神经反噬（粉色大象最敏感者）
- **病灶表现**：
  若提示词中出现“严禁掐掌心”、“严禁说教”，Kimi 极易在正文中写出反向澄清（如“她没有掐掌心，只是……”或“我不是在教你”）。
- **特供药方**：
  - **100% 正向物理动作置换**：绝对不检索任何负面词，将注意力完全放在手头抓握硬物、视线物理阻断等具体动作上。

### 3. 欧化主语与“他/她”代词口吃（最顽固病灶）
- **病灶表现**：
  受 SVO 结构支配，几乎每段、每个分句都以人称代词打头（“他端着……他蹲下……他抓起……他按住……”），导致语流寸断，读起来极不连贯。
- **特供药方**：
  - **承前省略（Pro-drop）**：同一主体的动作坚决砍掉“他/她”，直接由纯动词流衔接；
  - **客体主语化**：多用器物、身体部位（“粗陶盆磕上石砖”、“指尖抠起布边”）起句；
  - **严禁相邻句代词连珠**：相邻分句严禁连续使用相同人称代词打头。

### 4. 叙述层破折号与旁白自我纠偏癖
- **病灶表现**：
  长文叙事中，Kimi 易用破折号制造叙述者内心的悬停或伪纠偏（例如：`你微微偏过头—— 不，你没有。`）。
- **特供药方**：
  - **叙述层破折号 100% 绝对清零**：正文中绝对禁止输出任何“——”！所有纠偏与悬停一律写实为当下的客观停顿或直接陈述；
  - 严禁借破折号搞自问自答式的旁白加戏。

### 5. 网文突发电击副词惯性（“骤然/猛地/死死”）
- **病灶表现**：
  在张力转换或肢体动作时，下意识插入“骤然暗了一下”、“猛地亮起”、“死死按住”等戏剧性副词，破坏真实物理阻尼。
- **特供药方**：
  - **突发副词彻底清零**：叙述层严禁使用“骤然/猛地/猝然/死死”；
  - **物理滞后与沉降**：改用具象生理受力（“定住”、“光晕收敛”、“指节收拢”）。

## 二、 Kimi 交卷前定点拦截清单

在输出最终正文前，Kimi 需扫描拦截：
1. [ ] 正文中有无出现任何叙述层 `——`？（破折号计数必须严格为 0）；
2. [ ] 是否混入了“骤然/猛地/猝然/死死”等舞台剧抽搐词？（全部替换为动作停顿与骨骼受力）；
3. [ ] 全文搜索“像”字，核验是否有任何 4~6 字的句尾短比喻挂件？
4. [ ] 是否出现了带有“没有/不是”的否定式澄清？
5. [ ] 是否对齐了三大笔法范本（按范本 1 纯动词链推进消除句尾挂件，按范本 3 人动景出与碎砖律）？
6. [ ] 全文核验是否存在“他……他……他……”等单句碎切与句首代词口吃？（切忌走向生硬抹除人称的电报体，强制整合为“一主串多动”的连贯完整复句，保证句子行云流水般连贯好读）。
