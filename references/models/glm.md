# GLM 写作特征与适配参考

针对 GLM 系列模型（GLM-4、GLM-5.3 等）在中文叙事中常见的表达偏好，提供针对性的写作参考与建议。

---

## 一、 常见写作倾向与建议

### 1. 台词避免过度解释机理与动机
- **常见现象**：
  在写对白时，容易让角色条分缕析地解释当前法术机理或动机，显得过于坦诚自觉，把潜台词直接说白。
- **调整建议**：
  保留生活化关切、习惯性叮咛与当下互动的自然言语（如煮汤、添炭、问询冷暖），不用单字口令；避免让角色给对方详细讲解法术机制或长篇大论剖析动机。情绪与试探留在动作和未尽之言中。

### 2. 避免轻小说式浮空微表情
- **常见现象**：
  容易频繁使用“长睫轻颤”、“垂下眼眸”、“神色微敛”、“眼底翻涌”等脱离环境器物的浮空微表情。
- **调整建议**：
  动作与身边的具体器物产生真实的物理接触（如指骨磕在粗陶碗豁口上、小臂贴上粗糙墙板、掌根按在布料边缘）。

### 3. 避免借感知写全知读心
- **常见现象**：
  即使用限知视角，也容易下意识写出“你知道她此刻害怕了”、“你能感觉到某种不易察觉的动摇”等替对方做心理总结的句子。
- **调整建议**：
  不写“你知道/你明白/你看出她……”，只描写眼睛观察到的客观细节（如手心微汗、手腕骨节收紧）。

### 4. 避免四字成语机械对仗
- **常见现象**：
  写景和渲染气氛时容易成对出现对仗的四字短语（如“山风呼啸，冷雨敲窗；夜色深沉，寒意刺骨”）。
- **调整建议**：
  避免连续出现对称的四字句，景物描写依附在人物手头的具体动作上，长短句自然错落。

### 5. 避免突发副词与夸张抽搐
- **常见现象**：
  疼痛和戒备容易写得过于夸张（如“整个人震了一下”、“猛地挡住”、“肌肉硬得像干柴”）。
- **调整建议**：
  叙述中不用“猛地”、“骤然”、“死死”；真实痛感往往表现为动作停顿（手悬在半空停住）、身体发僵定住、顺着石壁慢慢往下滑了半寸。

## 二、 写作与检查要点

在输出最终正文前，GLM 需在自检回路中扫描拦截：
1. [ ] 对白中是否有角色像游戏NPC一样给对方灌输长篇机理解释？（若有，将设定说教删去，还原为符合人物关系的生活人话）；
2. [ ] 是否出现了“垂下眼眸/长睫轻颤/神色微敛”等浮空微表情？（若有，全部替换为手部与现实器物的物理受力）；
3. [ ] 是否出现了“猛地/骤然/死死/整个人震了一下/肌肉硬得像干柴”？（若有，全部替换为平实停顿与身体沉降）；
4. [ ] 正文中有无“你知道她……/你看得出她……”式的伪限知读心？
5. [ ] 景物描写是否存在对称的四字短语对仗？
6. [ ] 句尾是否挂载了塑料短比喻（如“像上了弦的弩”）？若有，强制按范本 1 纯动词推进清空比喻，或按范本 2 物化为触手可及的日常具体实物；
7. [ ] 是否对齐了三大笔法范本（纯动词链推进、具象实物喻体、人行动线碎景）？
8. [ ] 是否存在“他……他……他……”或“你……你……你……”等单句碎切与句首代词口吃？（切忌走向生硬抹除人称的电报体，强制整合为“一主串多动”的连贯完整复句，保证句子行云流水般连贯好读）。
9. [ ] 绝对禁止输出任何 HTML、XML、SVG 标签（如 `<svg></svg>` 等格式残片），直接输出小说纯正文。
