# DeepSeek 写作特征与适配参考

针对 DeepSeek 系列模型（V3、R1、V4-Flash 等）在中文叙事中的常见表达偏好，提供针对性的写作参考与建议。

---

## 一、 常见写作倾向与建议

### 1. 叙述层破折号清零（叙述层 0 处，避免同位语与补丁）
- **常见现象**：
  在叙述中较易依赖破折号，在动作、声音或反思后挂载 `——`（例如：`传来一声抽气——像是被牙关拦住`、`混在里面的是另一种声——踩进泥里`）。
- **调整建议**：
  - 正文叙述中不使用“——”。想要使用破折号的位置，替换为句号、逗号或独立短句：
    - ❌ `混在里面的是另一种声——踩进湿泥里带出来的那种闷力。` ➔ ✅ `混在里面的是另一种动静，是鞋底踩进湿泥里的闷响。`
    - ❌ `继续手上的活计——粗盐又抖平一层。` ➔ ✅ `手上活计没停，指尖把粗盐又抖平了一层。`
    - ❌ `她忽然开口——声音干哑。` ➔ ✅ `她忽然开口，声音干哑。`
  - 对白中不使用破折号表示日常说话中的停顿或犹豫，改用逗号或句号；破折号仅限外部剧烈冲撞打断。

### 2. 避免首句空泛天气与宏观比喻
- **常见现象**：
  习惯在第一段甚至第一句，用“天气/环境 + 宏观喻体”起笔（例如：`屋外雨声像一床湿透的厚棉被，把整座山都捂得喘不过气来`）。
- **调整建议**：
  开篇第一句的主语尽量不以空洞的“雨声/风声/夜色/天空”开头，而是直接由角色的手、脚、正在受力的道具或具体动作切入。环境在角色的具体行动中自然带出。

### 3. 避免机械排比对仗与密集四字词
- **常见现象**：
  语言功底较深，但有时容易前后句式过于对称、四字词密集递进，显得过于整齐舞台化。
- **调整建议**：
  打破匀速节奏，让长句随复杂动作顺承延展，短句随关键动作落锤，长短自然错落。不堆砌华丽成语，多用朴实具体的单字动词。

### 4. 避免过度理性公文式推演
- **常见现象**：
  在面对情感或非理性冲突时，容易让角色用过于滴水不漏的姿态去解释和梳理逻辑，冲淡了真实的人情味。
- **调整建议**：
  对白避免像公文答辩一样严密论证因果，保留日常对话的自然零散、生活关怀与真实人情。允许人物在高压情境下出现不可控的失误（如打翻水碗、动作迟疑）。

### 5. 避免夸张的舞台剧抽搐
- **常见现象**：
  容易将紧张与戒备推向极端夸张（如动辄“猛地攥住”、“整个人震了一下”、“指甲掐进石缝”）。
- **调整建议**：
  叙述中尽量不用“猛地”、“骤然”、“死死”；真实痛感往往表现为发僵、定住与停顿（手悬在半空停住、顺着石壁慢慢往下滑了半寸）。

## 二、 写作与检查要点

在输出最终正文前，DeepSeek 需在反思回路中扫描拦截：
1. [ ] 正文中有无出现任何叙述层 `——`？（叙述层破折号计数必须严格为 0）；
2. [ ] 第一句的主语是不是天气或比喻？（若有，将第一句删掉，直接从手头动作切入）；
3. [ ] 是否出现“猛地/骤然/猝然/死死/整个人震了一下/指甲掐进石缝”？（若有，全部替换为动作停顿或身体沉降）；
4. [ ] 是否存在连续 3 句结构对仗的整齐句段？（若有，砍碎其中一句改成短句）；
5. [ ] 成语数量是否超出 2 个？
6. [ ] 是否对齐了三大笔法范本（纯动词链推进、具象实物喻体、人行动线碎景）？
7. [ ] 是否存在“他……他……他……”或“你……你……你……”等单句碎切与句首代词口吃？（切忌走向生硬抹除人称的电报体，强制整合为“一主串多动”的连贯完整复句，保证句子行云流水般连贯好读）。
