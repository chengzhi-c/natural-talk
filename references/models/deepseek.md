# DeepSeek 专项神经代偿指南 (DeepSeek Model Adapter)

本文件为 **DeepSeek 宿主模型专用代偿协议**。针对 DeepSeek 系列模型（V3、R1、V4-Flash 等）在中文小说叙事中特有的底层神经偏好与写作病灶，进行定点压制与重构。

---

## 一、 DeepSeek 核心病灶与针对性药方

### 1. 叙述层破折号清零（硬指标：绝对 0 处，严禁任何同位语、揭示与动作连接补丁）
- **病灶表现**：
  DeepSeek 在叙述中具有强烈的“破折号依赖症”，极易在动作、声音、揭示或反思后挂载 `——`（例如：`传来一声抽气——像是被牙关拦住`、`混在里面的是另一种声——踩进泥里`、`继续手上的活计——粗盐又抖平一层`、`她忽然开口——声音干哑`）。
- **特供硬约束**：
  - **键盘封锁“——”符号**：在叙述层正文中，DeepSeek 严禁输出任何“——”！所有想要使用破折号的位置，一律替换为**句号、逗号或正面独立短句**：
    - ❌ 严禁：`混在里面的是另一种声——踩进湿泥里带出来的那种闷力。` ➔ ✅ 强制：`混在里面的是另一种动静，是鞋底踩进湿泥里的闷响。`
    - ❌ 严禁：`继续手上的活计——粗盐又抖平一层。` ➔ ✅ 强制：`手上活计没停，指尖把粗盐又抖平了一层。`
    - ❌ 严禁：`她忽然开口——声音干哑。` ➔ ✅ 强制：`她忽然开口，声音干哑。`
  - **台词层破折号封锁**：严禁在对白中使用破折号表示平缓语流中的犹豫、停顿或未尽之意（如 `“一会儿就——”` 严禁使用破折号，改用逗号或直接句号收束）；破折号仅限外部剧烈物理冲撞打断。
  - **统计铁律**：全文正文叙述层破折号数量必须精确为 0。凡输出哪怕 1 个破折号即判定不合格。

### 2. 首句天气与宏观比喻癖（清嗓开篇）
- **病灶表现**：
  DeepSeek 习惯在第一段甚至第一句，用“天气/环境 + 宏观喻体”作为沉浸起手式（例如：`屋外雨声像一床湿透的厚棉被，把整座山都捂得喘不过气来`）。
- **特供药方**：
  - **首句剥夺环境主语**：开篇第一句话的主语严禁为“雨声/风声/夜色/天空”，主语必须是角色的**手、脚、正在受力的器物或具体动作**。世界观与环境只能在角色的动作中带出，禁止单独成句升华。

### 3. 对仗与四字成语连珠强迫症（满分作文腔）
- **病灶表现**：
  中文功底极厚，导致生成时倾向于前后句式对称、四字短语密集递进、节奏整齐划一，产生“舞台剧朗诵”与“高考满分作文”的失真质感。
- **特供药方**：
  - **打碎机械对仗与匀速节奏**：严禁整齐划一的排比与字数对称句。让长句随复杂动作顺承延展，短句随关键物理动作落锤，长短自然错落，呼吸自如；
  - **成语配额硬封顶**：千字以内常规四字成语严禁超过 2 个。将华丽成语（如“小心翼翼/犹豫不决/怒目圆睁”）全部降级为粗暴单字动词（“顿、扣、压、砸、拧”）。

### 4. 逻辑过载与理性降级（冲突合理化陷阱）
- **病灶表现**：
  由于 DeepSeek 强大的推理逻辑链，在面对极端非理性对抗、羞赧生涩或暴烈冲动时，容易让角色用滴水不漏的成熟姿态去“平息”冲突，把角色写得过于圆滑老练。
- **特供药方**：
  - **注入现实物理失误**：在处理高压动作时，角色必须出现不可控的失误（例如：布条拉得过急勒裂伤口、药粉洒出碗沿、陶碗磕在石板上发出闷响）；
  - **阻断条分缕析的公文式推演**：对白严禁带有严密公文式的逻辑论证（避免角色在私人独处中像做答辩一样梳理因果）；保留日常对话的自然零散、犹疑、生活关怀与真实人情。

### 5. 舞台剧暴烈痉挛与浮夸动作癖（二次元假痛感）
- **病灶表现**：
  DeepSeek 在被剥夺抽象情感词后，极易将肢体张力推向浮夸极端（如动辄写“猛地攥住”、“整个人震了一下”、“指甲掐进石缝”、“下颌咬出两条筋”），沦为舞台剧和动漫分镜式的表演性痉挛。
- **特供药方**：
  - **突变副词彻底清零**：叙述层严禁使用“猛地”、“骤然”、“猝然”、“死死”；
  - **严禁表演性剧痛**：严禁“整个人震了一下/指甲掐进石缝/咬碎牙关/肌肉硬得像干柴”；
  - **以静止与沉降置换抽搐**：痛感与防备的物理现实是**发僵、定住、停顿与沉降**（动作在半空停住放不下来、一口气憋在嗓子里、顺着石壁慢慢往下滑了半寸、掌心压平在石面上硌出白印）。

## 二、 DeepSeek 交卷前定点拦截清单

在输出最终正文前，DeepSeek 需在反思回路中扫描拦截：
1. [ ] 正文中有无出现任何叙述层 `——`？（叙述层破折号计数必须严格为 0）；
2. [ ] 第一句的主语是不是天气或比喻？（若有，将第一句删掉，直接从手头动作切入）；
3. [ ] 是否出现“猛地/骤然/猝然/死死/整个人震了一下/指甲掐进石缝”？（若有，全部替换为动作停顿或身体沉降）；
4. [ ] 是否存在连续 3 句结构对仗的整齐句段？（若有，砍碎其中一句改成短句）；
5. [ ] 成语数量是否超出 2 个？
6. [ ] 是否对齐了三大笔法范本（纯动词链推进、具象实物喻体、人行动线碎景）？
7. [ ] 是否存在“他……他……他……”或“你……你……你……”等单句碎切与句首代词口吃？（切忌走向生硬抹除人称的电报体，强制整合为“一主串多动”的连贯完整复句，保证句子行云流水般连贯好读）。
