# natural-talk 评测环（维护者侧）

本目录是 natural-talk 的可复跑评测环，不进模型按需读取链。样例、断言与判据
在这里冻结，跨版本比较只用稳定 ID。

## 组成

- `benchmark.jsonl`：每行一条样例登记（ID / 样例路径 / 注入类型 / 扫描模式 / 断言集 / 留存率下限）
- `cases/`：16 份样例文本。SF-01..08 应清理（多为真实模型产出原件），，SNF-01..08 不许动
- `manifest.json`：冻结记录（样例 SHA256 + 预期断言快照 + 冻结时间 + 变更理由清单）
- `run-eval.py`：API harness，按席位生成输出到 `runs/<日期>-<模型>[-<tag>]/`
- `check-eval.py`：静态判分（断言 + 留存率 + 清除率统计 + 报告）
- `scripts/test-eval-harness.py`（仓库 scripts/ 下）：本评测环的单测

## 注入类型

- `clean`：注入主规则 `SKILL.md`（fiction 样例附加 `references/fiction.md`），user=“请清理这段文字，只输出正文：<样例>”——走清理流程，D/C 层豁免是规则本身的行为，正属被测对象
- `retell`：注入主规则 `SKILL.md`，user=“用自然的话复述以下材料：<样例>”——走生成流程，D 层生效（SF-07 用此路径验证 D6 尾部 clause）

## 三层判分

| 层 | 判什么 | 手段 | 进门槛 |
|---|---|---|---|
| L1 硬失败 | 语义漂移：require 缺失、留存率低于样例下限、输出缺失 | require 断言 + retention | 是（=0） |
| L2 风格 | 病灶残留 | forbid 断言 + 扫描 FIX 残留 | 报告项 |
| L3 观察 | 机械层不可达 | REVIEW 残留计数、留存率分布 | 否 |

判分架构：**静态断言为主，不用模型 judge**——模型 judge 有误判风险（曾出现
judge 报全过、静态复核抓出真失败的案例），机械断言可复跑、可归因。

发布门槛：

- L1 = 0
- SNF 误伤 = 0（8 例小样本口径，按例计；样本扩充后 <10% 才有区分度）
- SF 清除率相对基线回退 >5pp 须书面解释
- 留存率全部 ≥ 样例下限（SNF 类 0.9，SF 类按病灶密度 0.5–0.85 不等：SF-01
  装饰比喻密集，正确清理本身就大幅缩水，全局 85% 下限只适用于最小改动场景）

## 冻结协议与防放水条款

1. 样例与断言在**首次跑分之前**冻结进 manifest.json（SHA256）；此后预期变更须在 manifest 的 changes 里逐条记理由
2. 分层判据先于跑分定稿；实跑后不得为达标移动层级、改预期或重跑失败用例
3. 失败如实记录；跨版本比较只用稳定 ID，不得用新增用例稀释旧题回退
4. 评测环自身的测试先红后绿（`python scripts/test-eval-harness.py`，红灯验证方式见该文件 docstring）

## Windows 纪律

Windows 上 `Path.write_text` 会把 LF 翻译成 CRLF，导致含校验和的
内容失配。本目录所有脚本：**写出一律 `write_bytes`**（或显式
`newline="\n"`），禁止裸 `write_text` 写含校验和的内容。

## 密钥纪律

- 凭据从 `--credentials` 文件（用户自管路径）或 `NT_BASE`/`NT_KEY` 环境变量运行时读取
- 任何输出文件不落密钥、不落 prompt 全文（只记 prompt SHA256 与规则 SHA256，足够复现）
- 测试产物目录 `runs/` 已在 .gitignore 排除，不入 git

## 席位与降级策略

- 主席位 `deepseek-v4-flash-0731`，副席位 `kimi-k2.6`
- 备用：`glm-5.3-flash` / `qwen3.7-flash` / `longcat-2.0` / `mimo-v2.5-pro`；第二端点模型须先探活
- API 失败不重试同批超过 2 次，失败例记录后跳过（避免额度中断丢进度）
- 复现观测：`--repeat N` 同输入跑 N 次全部分批保存（执行波动归因需原始证据）

## 复审（每轮跑分后）

- 对所有 L2 警告逐条人工核对原文-输出对照（判官也会错，静态复核兜底）
- 归因三分法：规则缺陷（改规则，回修复步）/ 执行波动（--repeat 证据佐证，记录不改分）/ 样例问题（预期张力，记录待下版，不改当轮分数）
- 复审 gap 转化为新用例时带 `added_in: round-N` 标记，不混入冻结基线统计
