# 上游对照表（lieflat-less-ai-tone）

文本层 B1–B11 派生自 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone) 的改写规则。上游是自我修正型研究（公开测量失误记录，规则随研究修订），本表锁定基线版本并记录每条的处置，兼作上游升级时的 diff 清单。

- 基线：本地快照（来源仓库 github.com/larashero3-dotcom/lieflat-less-ai-tone，本地副本无 git 历史）
- 上游升级流程：对照下表逐条 diff，倍率变化超阈值或条目增删时同步本仓库并重跑回归门（docs/regression-baseline.md）

## lite 裁剪依据

`templates/system-prompt-lite.txt` 采用分层配额：D 层保留 D1（评判越界）、D2（开场收尾）、D4（给倾向）——对话层是 natural-talk 相对上游的唯一增量，token 敏感版本不裁 D 层；B 层按上游实测倍率取 top-5：B4（空转句 9.4×）、B9（7.3×）、B3（4.4×）、B1（3.4×）、B10（3.2×）。上游数据更新时可机械重裁 B 层；D 层待本项目对话组数据沉淀后按效应量复核。

## 上游倍率的时效提醒

同一特征在不同模型间极差可达四十倍（破折号：DeepSeek 5.16，GPT 0.11），且模型迭代持续向人类文风收敛。上游自述所有频率数值为特定时点观测。本仓库不随单模型行为调整规则，只在上游研究整体修订时同步。
