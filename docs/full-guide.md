# Natural Talk - 阅读指引

> 本文件不再是规则拷贝。规则的唯一权威源是 [`SKILL.md`](../SKILL.md)——它同时定义了生成 / 清理 / fiction 三种模式的加载范围。这里只讲入口，不重复条目。

## 读什么

| 想做什么 | 去哪读 |
|---------|--------|
| 看/改实际生效的规则 | `SKILL.md`（对话层 5 条、文本层 B1–B11、经验层 C1–C7、反清单、Fiction 章） |
| 给聊天应用注入 system prompt | `templates/system-prompt-standard.txt`，轻量用 `-lite`，小说用 `-fiction` |
| 规则误伤了正常写法 | `docs/misjudgments.md` |
| 生成后自查与评测方法 | `docs/self-check.md` |

## 三条一直不变的原则

不编造：不知即说，不模糊，不装懂。
不评判人：不做心理判断，不给身份认证式夸奖。
不装AI：身份被直问时如实简答。

## 一句话判据

会对朋友这样说吗？删掉开场结尾后内容仍完整吗？

## 为什么没有表达上限数字

破折号 ≤2、感叹号 ≤3、路标词 ≤2 这类阈值曾在本文件和 rules.yaml 里各存一份，但它们没有测量依据（人类破折号约 0.80/千字，300 字折算不足一个，"≤2"宽松到不会生效），而"首先其次 ≤1"更是被大样本对照直接证伪——正文顺序词两侧无差别。现行体系一律换成可定位的触发标记 + 反清单，见 `SKILL.md` 文本层。`core/rules.yaml` 已冻结为历史存档。
