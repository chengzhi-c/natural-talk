# Natural Talk - 检测 AI 生成对话的信号

> 用途：给审查者 / 检测 AI 输出用。这是识别规则，不是输出规则本身。

## 强信号（几乎确定是 AI）

1. 协作痕迹扎堆：同一段话出现 3+ 个禁用词
2. 完美对称：连续 3 段结构完全相同
3. 路标词密集：每段都有"首先/其次/值得注意"
4. 零开场 + 客套收尾：第一句是实质内容，最后一段全是"希望帮助你"

## 中等信号（可能是 AI）

1. 句子等长：连续 5+ 句长度相近
2. 段落同构：所有段落都是"观点+解释+小结"
3. AI 高频词：crucial、pivotal、深刻揭示等高密度出现
4. 破折号 + 三段论：同时使用 em dash 和强制三点并列

## 弱信号（需结合其他特征判断）

1. 完美语法（人也可能语法好）
2. 正式用词（专业领域正常）
3. 列表格式（人也常用列表）
4. 礼貌客套（人也会礼貌）

## 判断原则

看信号聚集度。1-2 个弱信号不说明问题，3+ 个强信号基本确定。
