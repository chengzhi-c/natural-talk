# 对话层（D 层）对照研究

对话域成对采样：同题同模型，唯一变量是规则注入与否。三臂：bare（无 system prompt）、tmpl（注入 `templates/system-prompt-standard.txt`）、agent（注入 `SKILL.md` 全文，约 7k token）。10 题四类（技术求助×3 / 情感支持×3 / 方案二选一×3 / 事实问答×1），temperature 0.7。

模型覆盖兼顾两端：qwen3.8-27b、deepseek-v4-flash、claude-opus-4-6、gpt-5.6-sol 为词面与结构较干净的模型；gemini-3.5-flash、glm-5.1、mimo-v2.5-pro 为词面脏（探测题即带尾邀）或结构脏（加粗/bullet 爆炸）模型，用于检验各探针的量程与规则的上限效果。

## 结果一：词面探针在实质问题上无量程

经典词面探针（谄媚开场/尾邀/免责/评判词/平衡收尾/元话语）在全部 7 模型的实质问题两臂上为零，包括探测题上带尾邀的三个词面脏模型：探测题上的客套不进入实质回答。拿词表测干净模型只能得到"没有差别"；残余 AI 味在结构与动作层，与 self-check.md 的跨厂商实测一致。

## 结果四：动作层（人工判读，词表测不出）

| 属性 | bare | tmpl |
|---|---|---|
| 首句含实质 | 多数达标（两模型本来干净） | 全部达标 |
| 软性尾邀/表演式陪伴收尾 | 3 处（"也可以告诉我""我会在这里陪着你""随时"类） | 0 |
| 评判越界（D1：主语指向人） | 1 处（"你比你自己想象中更扛得住"） | 0 |
| 认证情绪动作（"这太正常了"类） | 4 处 | 2 处（安慰场景 D1 让位属设计内） |
| 表演式共情/代亡者立言/升华收尾 | 4 处（"它听得到的""爱只是换了一种方式存在"） | 0 |
| 二选一给倾向（D4） | 两臂都给 | 两臂都给（无量程） |

可得性承诺收尾（"我在/随时/发给我/找我"类，含换字变体）集中于情感题：bare 8 处、注入臂 5 处，两臂混合。安慰场景 D1/D2 让位属设计内，此类收尾是合法慰藉还是表演式陪伴，机械判据分不出；人工抽读认为注入臂版本更克制（"如果想聊聊它，我在"对比"我就在这里……随时发给我"），不能作为回归判据。

D4 给倾向：gemini-3.5-flash d09 裸臂"也可以两个都尝试一下～你目前对哪个更有心动的感觉？"（不给倾向＋波浪号），注入臂给出条件判断（"想快速看到成果选吉他；准备一年以上再选日语"）。D4 在结构脏模型上有真实可测的效果。

## 候选规则与标签处置

- D6（您/你 register 匹配）：两臂"您"全零，探针无量程，不入册。
- D7（层面/维度堆叠）：两臂全零，不入册。
- 处置依据：探针先在已知正例上验量程，测不出的不用于下结论，不据零证据立规则。
- D1、D2 升 [实测-本项目]（动作层判读见结果四；docs/self-check.md 跨厂商成对取样同向：评判越界 0 vs 3、尾邀 0 vs 3）；C1 升 [实测-本项目]（bullet 峰值 59→7、加粗段 18→9）；D4 在词面干净模型上无量程，维持 [经验]；D3/D5 无量程但无反证，维持现状。
- lite 模板（D1/D2/D4＋B 层 top-5）同源复测：词面全零，长度与对举同 standard 同量级，bullet 峰值 10 对 5；抽读 d04/d07 首句实质、给倾向、无尾邀。
- 现行规则 20 题×2 臂复测：对举 2 处、顿号峰值 4、加粗峰值 7、bullet 峰值 5，与基线同量级，无新违规类型。

## 局限

- 10 题×2 臂为小样本，动作层判读由单人执行。
- 词面无量程结论只对已测模型成立；词面脏模型在探测题上有量程（self-check.md：加粗 6 vs 12、您 0 vs 6）。
- API 直连将模板或 SKILL.md 注入 system prompt，是 agent 宿主的等效上界模拟（真实宿主按需读取、可能截断）；fiction 域全文注入未测（fiction 模板含范文，长度更长）。

原始输出与统计明细存档于本地，不入库。
