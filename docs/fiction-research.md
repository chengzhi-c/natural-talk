# Fiction 层对照研究

公版人类小说与模型裸生成在 fiction 红线标记上的频率对照，用于回答两个问题：红线所涉句式在人类小说中是否存在；它们在哪些模型上高频出现。

## 设计

- **人类侧**：公版小说 13 篇 110,633 字——鲁迅《呐喊》10 篇（孔乙己/药/一件小事/明天/风波/故乡/社戏/端午节/肥皂/在酒楼上，另含彷徨《祝福》《伤逝》）＋萧红《呼兰河传》第一/三/五章。来源 zh.wikisource.org，语料在 `corpus/human/`
- **生成侧**：11 模型 × 6 情节提示（对抗/日常/回忆/婚内争吵/夜班悬疑/儿童视角），裸 prompt 无风格指令，temperature 0.7，共 58 篇 68,088 字。部分模型篇数偏少（kimi 2 篇、minimax 3 篇），相应频率只作方向参考
- **测量**：`scripts/measure-fiction.py`（按模型分解），正则词表，逐项每千字频率
- **F1 为代理词表**（终于明白/意识到/第一次觉得/才懂等），命中须人工复核"角色认知 vs 作者盖章"

## 发现

1. **B5 破折号模型间极差 12.7×（kimi 3.72 vs gpt 0.29）**，复现上游"极差四十倍"的结构：Claude 2.46 偏重（上游 Claude 4.25 同向）、GPT 0.29 极轻（上游 GPT 0.11 同向）、Grok/Gemini 轻。合计侧 1.22× 接近人类 1.20，均值掩盖极差；破折号须按模型判，"AI 平均"口径不可用。
2. **F3 生理反应模板集中于国产系**：deepseek-pro 0.348、qwen 0.318、deepseek-flash 0.226、mimo 0.140；Claude/GPT/Gemini/Grok 全零。瞳孔/指节模板的分布集中于特定模型群，"模型通病"的提法不成立。F3 红线对国产系为高频实用规则，对海外系为零触发。
3. **Claude 的 fiction 输出最接近人类侧形态**：F1/F3/F5 全零，仅 F2 0.164（"笑意没到眼睛"类）与破折号偏高。
4. **F1 作者盖章：qwen 0.159、gpt 0.146、deepseek-flash 0.113**，人工复核命中均为"第一次觉得，有些话迟了，但爱没有迟"式作者升华。GPT 在 fiction 域写升华收尾，与其对话域词面全零形成对照：同一模型两域表现不同。
5. **F5 对举集中在 kimi/minimax**（1.59/0.55），海外系几乎零——与 B5 一样，模型间差异大于"AI 通病"。
6. **B8 翻译腔五种在 fiction 生成侧几乎不出现**：上游 2.6–5.3× 的倍率来自论述文；fiction 生成侧不写这些句式。带入 B8 无害（白名单式），但其依据仅是"不排除"。
7. **"的链"反向（约 0.12×）是时代混杂**：民国白话的"的"字链远密于当代生成文。受时代文法影响的探针在本语料上无效。

## 局限

- **时代错位**：人类侧为 1920s–1940s 白话，生成侧为当代白话。词面层探针（F2/F3/F5）受影响小，文法层探针（B8、的链）受影响大，后者结论不可用。
- **生成侧样本偏小**（58 篇 6.8 万字）：单模型 2–9 篇，频率高值（kimi 3.72）受样本量放大，作方向参考不作精确倍率。
- **人类侧作者集中**（鲁迅 10/13）：单人风格偏置。
- **两批采样经由不同中转网关**：同模型（deepseek-flash/kimi）跨网关路由，存在路由差异可能。

## 对规则的影响

- Fiction 章"手艺规则，不可统计检验"的总述维持；F1/F3/F5 与对举结构有本项目对照数据（模型间差异表见上），在 Fiction 章标注。
- fiction 清理模式带入清单（F1–F5＋B1/B5/B6/B7/B8）不变：B1 有据，其余无害。
- 红线不新增不删减——58 篇样本支持"F3 对国产系高频实用、对海外系零触发"的分层描述，但不足以支持规则增删。

## 复算

```bash
python scripts/measure-fiction.py corpus/human corpus/ai
```

语料不入库：人类侧取自 zh.wikisource.org（篇目见设计节），可独立取回；生成侧存档于本地（`corpus/ai/` 文件头含模型名与参数），配合 `scripts/measure-fiction.py` 复算表中数值。
