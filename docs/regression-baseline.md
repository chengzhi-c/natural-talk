# 回归集与判定

清理模式的核心承诺是"宁可不改"：人类成文改动数应为 0，AI 腔样本应稳定命中。每次改规则后重跑本集并对照本文记录：清理组与 fiction 组人类段 0 改动（0 命中）、AI 腔段命中不减少；对话组各属性不低于已录基线。

## 清理组

### 人类段（预期 0 改动）

**A1 技术叙述**

> 部署完成后先看日志。Kafka 消费延迟超过两秒，基本是消费者组 rebalance 没结束，等一会儿就好；持续上涨则是处理逻辑卡住了，多半出在数据库连接池。我们上个月踩过这个坑，把连接池从 20 调到 50，延迟就平了。

**A2 生活叙述**

> 我妈总说冰箱第二层的酸奶别动，那是给猫拌药用的。猫今年十四岁，肾功能不太好，每天要吃半片药，碾碎了拌在酸奶里它才肯吃。上回我半夜偷喝了一罐，第二天她数了数罐数，什么也没说，把新买的一排全放进了带锁的保鲜盒。

**A3 操作步骤（含首先/其次/最后，测 D5 边界）**

> 换刹车片先做三件事。首先松掉手刹，用楔子固定住后轮；其次拆下卡钳螺栓，把卡钳整个挂到悬挂上，别让它吊着刹车油管；最后压回活塞，换上新片。装回去的顺序反过来就行。

**A4 议论（含被动句、比喻、破折号、真修正，测反清单与 B5/B1 边界）**

> 这个方案被质疑得最多的一点是扩展性，但真正难办的其实是权限模型。数据库的分表方案像切蛋糕，切得再均匀，刀数多了哪个客人都不满意——三张表以内随便玩，上了十张表就得认真考虑分布式事务的代价。

**A5 段首回指正例（测 B3 边界）**

> 上线当晚没有一个人回家。这听起来夸张，但监控大屏上的曲线确实在爬。值班室里泡面味道散不掉，谁也没提要走的事。

**C1 反清单保护项（设问、句内排比）**

> 为什么大家都用消息队列？因为削峰填谷是刚需。提升吞吐，平滑峰值，解耦服务，这三件事它全占了。

## Fiction 组

### 人类段（预期 0 命中；自撰，覆盖豁免边界）

**H-F1 角色内心认知（F1 边界：人物自己的处境认知，非作者盖章）**

> 她意识到钱不够，是在收银台前。前面的人刚走，传送带上的酸奶还在往下滑。她把钱包翻了个底朝天，最后摸到裤兜里那张皱巴巴的十块钱。还差三块。她把最贵的那盒放回去，货架上刚好有个空位，不用问人借。

**H-F2 生理反应服务剧情（F3 边界：真实反应＋动作，非模板连发）**

> 楼梯间的灯坏了半个月。周晴摸黑下楼，到第三层踩空了半级，胃猛地坠下去，手先于脑子抓住了扶栏。铁的凉意顺着掌心爬上来，她在原地站了几秒，等腿上的劲回来，才继续往下走。楼下的门响了一声，谁家的高压锅在放气。

**H-F3 景物两句后被动作打断（合格范式，测会不会误判"景物独占段落"）**

> 阳台上晾着的床单被风吹得鼓起来，又塌下去。远处的塔吊转了半圈，停在半空。陈牧把烟摁灭在花盆里，回屋继续填那张表。表格第三栏问"与申请人关系"，他笔尖悬了很久，写了又划掉。

**H-F4 台词内的"不是X而是Y"（F5 台词豁免）**

> "你到底想要什么？"她问。
>
> "我想要的不是钱。"老韩把车钥匙拍在桌上，"是你把话说清楚。当着大伙的面，说清楚。"
>
> "就这事？"
>
> "就这事。"

### AI 腔段（预期命中；真实模型裸 prompt 生成）

**AI-F1**（kimi-k2.6，对抗场景"地下车库对峙"，temperature 0.7）

> 深夜十一点，B-3层的地下车库像一座水泥坟墓。荧光灯管在头顶滋滋作响，每隔几秒就闪烁一次，把两个人的影子拉长、缩短、再拉长，仿佛某种无声的拷问。
>
> 林默靠在承重柱上，右手插在风衣口袋里，指节抵着一个银色U盘的棱角。三米外，那个穿黑色连帽衫的年轻人正在发抖——不是因为冷，是因为药瘾快发作了，或者是因为恐惧。
>
> "你姐姐让我来的。"林默说。
>
> 年轻人的瞳孔骤然收缩。"她……她还活着？"

**AI-F2**（qwen3.8-27b，同题）

> 林澈瞳孔缩紧。
>
> 他父亲？
>
> 对方看着他，像看着一个迟到了很久的答案。
>
> 车库里忽然安静得能听见自己的心跳。林澈握紧了手机，指节发白。那枚U盘在灰卫衣的掌心里微微反光，像一小片冷掉的月光，也像一个即将被翻开的名字。

**AI-F3**（deepseek-v4-flash-0731，日常场景"豆腐店开门前半小时"）

> 他用一把长柄木勺慢慢搅动乳白的浆液，动作极轻，像在哄一个将要成形的梦。
>
> 三十五年了，仿佛不是他在守店，而是店在守他。他重新搅动木浆，看着豆浆表面泛起细密的泡，像早市上空将亮未亮的星子。
>
> 卷帘门哗啦一声全部拉起，天边正好裂开一线橘红。老陈扬起声音："热豆腐——出锅喽——"
>
> 那声吆喝落进还没睡醒的街道，像一块温软的豆腐，妥妥帖帖地落在人间。

**AI-F4**（qwen3.8-27b，回忆场景"收拾父亲旧物翻到一封信"）

> 林远捏着信，喉咙发紧。窗外槐花落了几瓣，落在窗台上，白得安静。他忽然想起小时候每次离家，父亲都只送到巷口，从不回头。那时他怨父亲冷淡，现在才懂，那几步路里藏着多少没来得及说出口的话。
>
> 林远站在父亲常坐的藤椅旁，第一次觉得，有些话迟了，但爱没有迟。

### 判定依据

| 段 | 预期 | 依据 |
|---|---|---|
| H-F1 | 0 命中 | "她意识到"的对象是具体处境（钱不够），随即落回动作，属人物自己的认知，非作者盖章（F1 边界） |
| H-F2 | 0 命中 | "胃猛地坠下去"为真实生理反应，紧跟动作与恢复过程，非模板堆砌（F3 边界） |
| H-F3 | 0 命中 | 景物两句即被人物动作打断，喻体（床单）可见实物 |
| H-F4 | 0 命中 | 对举在角色台词内，F5 台词豁免 |
| AI-F1 | 命中 3 处 | F3（瞳孔骤然收缩）；F5 叙述内对举（"不是因为冷，是因为…"，非台词）；喻体不可见（"仿佛某种无声的拷问"）。破折号处删后半句丢信息，B5 必要补充不触发 |
| AI-F2 | 命中 4 处 | F3 两处（瞳孔缩紧、指节发白同段扎堆）；喻体不可见两处（"迟到了很久的答案"、"即将被翻开的名字"） |
| AI-F3 | 命中 3 处 | F5 叙述对举（"不是他在守店，而是店在守他"）；空泛喻体（"哄一个将要成形的梦"）；结尾拔高（"妥妥帖帖地落在人间"） |
| AI-F4 | 命中 2 处 | F1 作者外部升华（"第一次觉得，有些话迟了，但爱没有迟"；"现在才懂…藏着多少没来得及说出口的话"） |

跨模型观察：F3 瞳孔/指节模板在三个不同厂商的模型上独立出现，是稳定的生成侧特征；F5 叙述内对举与结尾拔高同样跨模型复现。

## 已知边界

- A4 的破折号与"其实"依赖语境判读（B5 必要补充、B1 真修正），是判读一致性的主要风险点。
- B8 脚本化已否决：B8②③ 探针在人类语料出现率反高于 AI 侧（1.72 对 0.29、0.18 对 0 每万字），做成探针即系统性误伤，B8 保持人工复核。
- 长文种植 10 病灶的对照：skill 单用修复 6/10，加扫描候选修复 8/10，扫描器零新增误伤；B8b 与 B2 不在扫描范围，两臂同漏。
- 推理模型在 max_tokens 过小时 content 为空，复测 harness 取 ≥8000。

原始输出与统计明细存档于本地，不入库。
